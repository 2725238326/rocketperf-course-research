# 065：桌面图形界面 rocketperf-gui.exe

日期：2026-10-15。任务：GUI-001（READY；DOC-004 占用 WIP，未转 ACTIVE）。分支 `feature/gui`，工作树 `E:/Work/火发原理-gui`。

## 依据与选型

老师要求发布版可以是“控制台形式、带用户友好界面形式、微信小程序形式或APP形式”，核心计算须用 C 语言。控制台版已满足要求；本批次加做界面版，用于展示。

GitHub CLI 检索比较了 webview、Nuklear、raygui、microui、libui-ng、Dear ImGui/ImPlot。选 webview 0.12.0：MIT 许可，C API，用 Windows 自带 WebView2 渲染，中文与输入法正常，可静态链接成单文件。本机 MinGW-Builds 14.2 先做最小编译与运行探针，再正式接入。RPA（商业闭源）与 RocketCEA（GPL，Python 包装 Fortran）与“核心全 C、发布不依赖 Python”冲突，不作为基础。

## 结构

- `src/gui/gui_bridge.c`：扁平 JSON 请求经白名单映射到既有 C 求解器（与 CLI 相同的 HP、冻结喷管、背压评估、成对比较、绝热循环），失败保留 C 状态码与原文消息。核心模块未改动。
- `src/gui/gui_main.c`：WebView2 窗口；每个请求在工作线程执行 `rp_gui_handle`，退出前等待在途任务。页面资源以 RCDATA 嵌入 exe，运行时拼装。
- `src/gui/web/`：五个模块（总览、燃烧室、喷管、推进剂、循环）加说明页，自绘 SVG 图表与推力室/循环示意。页面只做单位换算和显示，数值全部来自 C。
- `tools/gui_build.py`：严格编译选项构建，输出静态 exe，检查 DLL 导入只含系统库，`--dist` 生成便携目录。`tools/gui_dev.py` 用同一 C 桥接做浏览器预览。
