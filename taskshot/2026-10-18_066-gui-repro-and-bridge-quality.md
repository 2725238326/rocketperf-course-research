# 066：GUI 输入复现与桥接质量

日期：2026-10-18  
分支：feature/gui

## 变更

- JSON 请求解析按 RFC 数字语法检查，拒绝前导零、1.、1.e3、不完整指数、截断 Unicode 转义和顶层重复键；输出 double 使用 17 位有效数字。
- 循环参数扫描和推进剂对比扫描的点数要求整数。
- 循环 GUI 求解返回完整 SI 输入 INI。页面可下载本次真实求解输入，复制对应 CLI 命令，避免命令只指向未包含覆盖值的原始案例。
- 燃烧室复制命令使用当前室压；循环案例切换使用请求 token 忽略过期结果，切换期间清空旧图表和账目。
- 循环编辑框支持键入和失焦触发重算，回车触发一次求解。
- 统一质量入口新增原生 GUI Release 构建和 GUI 桥接回归。
