# 架构图说明

五张图（作业总览、业务层次、模块架构、工作流程、计算流程）用同一套浅色配色，适合屏幕和打印。按层着色：入口蓝、计算橙、循环琥珀（虚线框表示研究原型）、输出青、核验紫、基础灰蓝、失败红。实线表示调用或数据流，虚线表示公共依赖、迭代或核验。

内容只保留结构和关键量：模块名和依赖取自`project/modules.json`，行数由脚本统计，命令和退出码取自`src/cli/main.c`。运行计数和细节说明不画进图，写在报告和模块文档里。

- **计算流程图 report-flow.svg**：用GB/T 1526符号画。入口层判断命令；计算层是`combustion`的HP平衡到冻结喷管；循环层是`cycle adiabatic`的轴功闭合迭代，预定义处理复用计算层；所有判断的“否”都汇到E，返回退出码2/3/4。右侧列出其余独立命令。
- **模块架构 components.svg**：6个运行时模块分三层，每张卡片底部标出文件数和行数。
- **业务层次 business.svg**：应用层的三个用例调用领域层的三个物理模型，每个模型标出它回答的问题和输出量。
- **工作流程 workflow.svg**：七步，每步对齐列出产物、模块和失败处理。

## 维护

配色和图元在`tools/diagram_style.py`，布局在`tools/architecture_views.py`和`tools/report_flow.py`。用`python tools/render_architecture.py`和`python tools/report_flow.py`生成；文字超出形状时脚本直接报错。`python tools/project.py check`会比对生成结果。改完在浏览器里看一遍。
