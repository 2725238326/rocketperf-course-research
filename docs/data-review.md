## 校验规则

`tools/check_data.py` 对参数 JSON 做以下检查：

- 记录 ID 不为空且不重复；
- `data_role` 只能是 `fact`、`derived`、`assumption`、`unknown` 或 `synthetic_benchmark`；
- 来源 ID 必须存在于来源索引，或明确指向项目文档；
- 单位、工况、模型用途和备注不能缺失；
- assumption 必须提供 `model_id`、有限的 `range.min/max`、理由；
- 数值不能是 NaN、无穷或布尔值；
- 数据集必须声明真实字段缺口和缺失值处理规则。

运行：

```powershell
python tools/check_data.py data/parameters/baseline.json
python tools/check_data.py data/parameters/assumptions.json
```

## 当前结论

- `baseline.json` 只保存可追溯构型事实、派生换算和教学基准；它不是两型发动机性能输入集。
- `assumptions.json` 只保存命名的、带范围和模型 ID 的研究情景；相同方法包络不表示两个型号参数相同。
- 真实飞行批次的室压、喷管面积比、O/F 定义、比冲工况和流量图谱仍未公开到可以直接进入求解器的程度。
- C17 计算应先读取研究情景或教学基准，结果中保留情景 ID；不允许把假设覆盖成 `fact`。
