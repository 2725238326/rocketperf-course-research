# 连续液体入口到绝热燃烧室与固定喷管

本地实现与运行：2026-10-05，不刷新线上型号事实。纯C链路已经接通：假设的纯CH₄/O₂单相温压 → 查表化学焓与每kg元素库存 → 九气相HP → 固定喉面积冻结喷管。它回答入口状态怎样影响同一喷管的计算性能，不是泵后状态、喷注可行性、完整循环或两型实装预测。

## 接口与能量边界

入口公共接口见[liquid_combustion.h](../include/rocketperf/liquid_combustion.h)，喷管包装见[liquid_nozzle.h](../include/rocketperf/liquid_nozzle.h)。热化学模块只依赖core；喷管层调用HP和已有冻结喷管，没有反向依赖或复制物性/平衡算法。旧气态与固定液态锚点API保持各自含义。

必须显式声明固定数据集 `coolprop710-cea334-liquid-molar-v1`、焓基准 `heos710-cea334-ideal-zero-298.15-v1` 和两路单相液体。入口域沿用[查表契约](liquid-feed-contract.md)：CH₄为100–140 K，O₂为80–110 K，两者1–20 MPa。燃烧室压力另给100–10⁹ Pa，O/F为0.1–20，HP在1000–6000 K夹逼；通过入口域检查不保证HP能夹逼或喷管背压在域内。

```text
x_f = 1/(1+O/F)，x_o = (O/F)/(1+O/F)
h_in = x_f H_f/M_f,CEA + x_o H_o/M_o,CEA
b_C = x_f/(1000 M_f,CEA)
b_H = 4 b_C
b_O = 2 x_o/(1000 M_o,CEA)
h_products(T,P,b) − h_in = 0
```

H为J/mol，M为kg/mol，b为kmol元素/kg混合入口。液体密度保留HEOS质量口径；化学焓、O/F及库存采用CEA质量口径。JSON同时返回两套分子量，不能把甲烷HEOS分子量偷偷代入化学库存。产品由相同元素质量定义构成，核验不仅检查H/C、O/C，也检查每kg产品的C/H/O量。

Q=0、入口动能=0、轴功=0是这个燃烧室的边界。入口压力只选择表格状态，不计算从贮箱到燃烧室的压升路径。即使入口压力低于或等于室压也仅是焓敏感性算例，不能解释为可工作的供给系统；需要泵/喷注压差时另建边界。密度在此作为入口审计量，不进入喷管求解。

NULL、非有限/非正量、非法数值策略返回`invalid_argument`；错ID/焓基准/相态和越域返回`out_of_domain`；夹逼、迭代和派生量数值失败分别保留原状态码。入口、HP或喷管任一后段失败，调用方输出均保持原值。内部库存归一化同时拒绝上溢和下溢，不把非有限残差拖进迭代。

## 实际对照与证明范围

[固定归档](../results/validation/liquid_combustion_v1/manifest.json)保存29次成功与18次拒绝C运行；九组入口/O-F各运行HP、面积比10及40喷管，另测双喉面积和5000 Pa背压。对应新跑18次CEA v3.3.4 HP/燃烧室冻结参考，保留输入卡、原输出、stdout/stderr、固定源码副本和构建/测试身份，不覆盖以前的气态或固定液态档案。

CEA使用自定义元素公式 `FEED_CH4 C 1 H 4` / `FEED_O2 O 2` 和**显式J/mol化学焓**，不是`CH4(L)`/`O2(L)`固定记录。输入卡里的298.15 K是指定焓记录标签，不是液体入口温度。显式焓先由保存的参考表独立插值构造，不读取C输出，避免用C输出给自己的参考补输入。固定CEA源码`input.f90`、`mixture.f90`及RP-1311示例已核对其单位/公式处理；运行清单固定上游commit、执行文件和编译数据库身份。

同物种、相同物性来源和冻结位置的软件对照不是实验验证。各条件最大绝对差：室温0.004406 K、c* 0.003504 m/s、真空有效速度0.006632 m/s；均小于现有打印精度容差。参考推力由CEA打印c*/Ivac和声明的Pc/At派生，最大差0.688109 N，不称实测推力。平衡Cp与冻结Cp不混比；残余/理想cp差异仍按单锚点对齐模型保留。

C测试检查入口摩尔/质量焓、质量分数、元素库存、平衡反应关系、HP残差≤0.01 J/kg、几何/背压关系和失败输出保持。Python独立复算保存表及NASA9关系，核对输入对应、强类型、完整文件、CEA卡和流协议；重算哈希后的焓/质量/库存/热量/状态/几何/来源/输入/参考等篡改仍拒绝。准备失败和最终语义失败都留FAIL尝试，不发布半份成功目标。

## 同几何入口响应

所有数值都是研究假设。固定Pc=10 MPa、At=0.01 m²、真空、面积比10；未变字段沿用CH₄ 120 K、O₂ 100 K、两路10 MPa、O/F=3.4。

两入口升温使混合焓增加28.863 kJ/kg、室温增加4.265 K，A10比冲增加0.280323 s，但流量下降，推力下降9.718 N；不能用升比冲直接宣称升推力或建议预热装置。这个小范围液体响应不等于以前298.15–900 K的气相预热研究，也不包含预热器能耗、压损或相变代价。

保持基线入口而将面积比从10改到40：出口面积0.1→0.4 m²、流量仍为55.218125 kg/s，比冲320.811939→345.468011 s、推力173.721212→187.072594 kN。这是理想几何收益，不是喷管质量、冷却、分离、侧载或寿命估计。双喉面积同时使流量、推力及出口面积翻倍，比冲不变；背压5000 Pa扣除500 N压力推力。O/F三个点仅作方法与趋势检查，未搜索最优比，也不能证明无凝聚碳。
