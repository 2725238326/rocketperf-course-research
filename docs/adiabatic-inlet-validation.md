# 同基准入口焓的绝热气相方法

本地计算日期：2026-10-05。固定参考沿用已核验的CEA v3.3.4；本轮没有新检索，不刷新型号资料的证据截止日期。

程序现在直接接收CH₄、O₂各自的入口比焓，用零热交换HP求燃烧温度，再求固定喉面积喷管。它是独立气相方法，**没有改变给定热状态外排循环**，也不是液态甲烷/液氧或煤油发动机模型。

## 输入和C契约

`RpCh4O2EnthalpyFeed`保存压力、O/F、两种纯物质入口焓、相态和基准。公开接口为`rp_ch4_o2_inlet_enthalpy`与`rp_ch4_o2_equilibrium_hp_enthalpy`，见`include/rocketperf/combustion.h`。

- 两种焓都包含形成焓，基准固定为NASA9 CEA v3.3.4数据集，不再额外加热值。
- 相态必须是气态。基准枚举是调用方声明，不是程序自动证明来源正确或相态稳定。
- 输入焓限制在各物种200–6000 K气相拟合端点的焓区间。这是软件护栏，不反演或伪造入口温度；固定拟合在此范围内cp为正，但不据此认证真实相态或高压理想气体近似。
- 压力100–10⁹ Pa、O/F=0.1–20；HP夹逼区间在1000–6000 K内。正压力/O/F超出护栏、未知相态/基准、焓越域返回`RP_OUT_OF_DOMAIN`；NaN/Inf、非正压力/O/F或错误策略返回`RP_INVALID_ARGUMENT`。
- 根不在区间中返回`RP_NOT_BRACKETED`；迭代预算耗尽/停滞返回`RP_NO_CONVERGENCE`。每种失败保持输出不变。

能量条件为`h_in = [h_CH4 + (O/F) h_O2] / (1 + O/F)`，求`h_products(T,p) − h_in = 0`。这是零热交换、无入口动能/轴功的无限面积燃烧室。HP不是给温度再倒算Q。旧温度入口TP/HP保持原契约；共享内部求解接收已验证的压力/O/F/目标焓，不通过虚构入口温度绕进旧API。

## 实际结果

气态方法基准：Pc=10 MPa，O/F=3.4，两种入口对应298.15 K同基准焓。本轮C物性查询保存CH₄的−4650159.6379939355 J/kg、O₂的−0.00040024263231910033 J/kg；混合入口为−1056854.4634897183 J/kg。

新旧入口得到相同温度、组分、诊断和喷管状态。HP温度3673.614567611 K，焓残差−0.00412250659 J/kg，低于0.01 J/kg门槛。两入口共用算法，所以等价性不是独立算法验证。

固定CEA卡的HP温度打印为3673.61 K，差+0.004568 K。A10/A40冻结c*、出口T/p、速度和真空有效速度按打印精度感知容差比较，逐字段差值保存在归档。两边同源物性，软件对照不是实验或整机认证；本轮没有新运行CEA的宣称。
