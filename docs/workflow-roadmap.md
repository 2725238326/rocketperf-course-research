## 可立即推进的四项工作

### 工作A：代码注释补强（1小时）

**目标**：每个计算函数都有清晰的物理约束说明

**检查点**：
```c
// 当前可能是这样
double hp_combustion(double Pc, double O_F) {
    // 计算HP
    ...
}

// 应该改为这样
/**
 * hp_combustion: 主室热力平衡求解
 * 
 * 物理约束：
 *   - 主室压力 Pc = 给定值 (Pa, 典型 10-30 MPa)
 *   - 氧燃比 O_F = 给定值 (典型 2-4)
 *   - NASA9物性数据库，298.15K参考焓
 * 
 * 输出：
 *   - T_combustion [K] 主室温度
 *   - h_combustion [J/kg] 混合气焓
 *   - composition [...] 成分（50物种）
 * 
 * 失败条件（返回错误码）：
 *   1: 温度<300K 或 >5000K
 *   2: 迭代不收敛
 *   3: 反应物无效
 */
```

**交付**：补充的注释提交到git

### 工作B：错误诊断信息改进（30分钟）

**目标**：用户能理解"为什么失败"而不是"错误码是什么"

**检查命令**：
```bash
grep -r "fprintf(stderr" src/
# 看每条错误消息是否有物理含义说明
```

**改进示例**：
```c
// 改前
fprintf(stderr, "Error: HP convergence failed, code=%d\n", code);

// 改后
fprintf(stderr, 
    "ERROR: Combustion chamber equilibrium did not converge\n"
    "  Chamber pressure: %.1f MPa\n"
    "  O/F ratio: %.2f\n"
    "  Iteration count: %d (limit: 100)\n"
    "Possible causes:\n"
    "  1. O/F ratio outside typical range (2.0-4.0)\n"
    "  2. Chamber pressure too low (<1 MPa) or too high (>50 MPa)\n"
    "  3. Propellant properties out of NASA9 coverage\n",
    Pc/1e6, O_F, iter_count);
```

**交付**：改进的错误消息提交
