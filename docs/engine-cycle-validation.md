# 绝热开式与富氧补燃循环

状态（2026-10-13）：`MOD-009`已有Debug/Release、六组统一质量、30个生产C文件静态分析和正式研究归档；任务语义验收/流转以worknow及任务板为准。归档记录`source_dirty=true`，表示采集时Git工作区有待提交内容（含未纳入项目的根目录ZIP）；确切C二进制、构建/测试和每个输入均以manifest哈希绑定。此状态在后续本地提交后不改写。本文不把本地工程验收说成两型模型的科学验证。

模型`adiabatic_single_shaft_cycle_v1`使用独立实现文件`src/cycle/adiabatic.c`，公共接口`engine_cycle.h`。`staged_combustion=false`选择燃气发生器外排；`true`选择全部氧化剂通过单个富氧预燃室及涡轮的补燃拓扑。组员代码已按[集成对照契约](cycle-integration.md)比较，其给定温度补燃计账/甲烷代理算例保持独立身份，详见[接收审阅](incoming-code-review.md)。

新接口与历史`prescribed_thermal_cycle_v1`并存。新模型不输入主室/预燃室温度，不通过任意热交换填补焓差；两燃烧过程Q=0，HP由入口形成焓及元素库存求解。恒密度泵把全部轴功加入流体焓；冻结涡轮抽取轴功，机械损失出系统，辅助功为外部负载。两路泵的公共出口压力与喷注/管路压降分别声明。

开式由给定涡轮出口压力计算比功，再求`m_branch=(P_pumps+P_aux)/(eta_shaft*w_t)`。支路质量、元素和出口总焓从主路扣除，外排推力乘声明的轴向投影。

补燃预燃室氧流量等于总氧流量，预燃室燃料为`m_ox/OF_pb`；剩余燃料直接入主室。由全部预燃室燃气承担轴功，求涡轮出口压力，最低允许`P_chamber+deltaP_return`。不能在该最低压力提供足够轴功时显式拒绝。实际回流的组分按`b_e=sum(y_i*a_ie)/M_mix`转成每kg元素库存；回流焓和新鲜燃料泵后焓加权后求主室HP。只计一次总消耗，既不重复添加燃料热值，也不把回流当作第二次外来供给。

适用域沿用九种理想气相CHO与1000–6000 K HP守卫；不是包含低温真实预燃室、烟炱或凝聚碳的通用模型。实际低温富氧/富燃工况超域时须拒绝。RP-1指定反应物的新循环研究接口有独立身份，不扩大旧`fixed RP-1 p=10 MPa/O-F=2.2..4.0`单喷管验证域。泵密度/效率及全循环压力、混合比、流量和几何均须留来源或研究假设。

四级段构型身份和研究情景在[两型研究表](two-vehicle-study.md)中对应。朱雀三号的燃气发生器架构采用家族层面资料；长十乙一级采用官方家族层面高压补燃背景，但不推断首飞子型后缀。长十乙二级循环没有与首飞装机身份相连的确证，开式/补燃都只是可比较的待判情景。

## 正式归档与复核范围

2026-10-12 `build/engine-cycle-second-probe/manifest.json`为早期开发试跑；它保留在`build/`，不是最终研究档案。正式复核归档位于[本版本](../results/research/engine_cycles_v2_20261013/manifest.json)，包含五个成功情景、四个预期拒绝、12张NASA CEA v3.3.4部件HP卡和814项状态关系复算。正式归档的哈希绑定应随这份唯一清单复核；它证明状态账和所测软件范围，不替代独立人员/实验科学验证。

在相同输入状态上，受限九气相C与CEA HP温度差绝对值不超过0.004 K。启用更丰富气相产物后差值最高约0.392 K，显示差异来自产物集合；这仍是软件方法对照，不是实验验证，也不扩大模型适用域。早期`engine_cycles_v1_20261013`原始归档保留作为v2校验修复前版本，不覆盖、不引用为推荐正式版本。
