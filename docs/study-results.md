## 2. 可复现的共同条件计算

运行：

```powershell
python tools/pipeline.py run --study area-ratio-ambient --case cases/research/s1_area_ratio_ambient.ini --run-id s1_review_20261002
```

默认网格为7个面积比、4个环境压力，共28点：19个`ok`、9个`out_of_domain`。输入为人为设置的空气基准：`gamma=1.4`、`R=287 J/(kg·K)`、`T0=300 K`、`p0=1 MPa`、`At=0.001 m²`，不代表两型火箭的燃烧产物。运行归档在`results/local/s1_review_20261002/`；重跑使用新的RunId，旧记录不能覆盖。

## 3. 改进方案：喷管膨胀适应性

面积比—环境压力是当前改进候选，后续还需要燃烧工质、合理输入范围、独立对照和代价分析：

- 有明确课堂公式和独立解析参考；
- 不依赖缺失的真实型号室压、O/F 或循环图谱；
- 能给出收益（低背压下压力推力/比冲增加）和代价（高背压越域、潜在过膨胀/分离风险、几何与控制复杂度）；
- 可以做同条件敏感性，而不是给某个型号编一个最优面积比。

在上述条件下，增大面积比有利于较低背压点。`pa=pe`是匹配膨胀，本模型允许；`pa>pe`被当前实现保守排除。这不证明流动已经分离，也不表示所有过膨胀都不能用准一维模型描述。要计算激波、分离或侧向载荷，必须扩展并验证模型。

节流与集总冷却作为副题保留在 L2 之后：没有热边界、支路质量和轴功率守恒验证前，不把节流比例乘法或冷却焓升写成发动机改进结论。

## 4. 两型对象的比较口径

真实两型比较采用“背景事实 + 缺口表 + 共同条件敏感性”三层结构：

1. 先比较推进剂、级段、并联数量、回收/二次启动等有来源事实；
2. 对四类对象逐字段标出未知，不用同系列或不同批次参数补齐；
3. 用 S1 共同条件结果解释“喷管膨胀与环境压力为什么会影响性能”，但不把结果贴到某个真实级段上；
4. 只有获得字段级原始证据并建立独立假设包后，才增加带对象标签的研究算例。

因此当前可以回答“工作方案和影响因素是什么、在共同模型下趋势如何”，不能回答“两个真实发动机谁的绝对比冲更高”或“某改进能提高真实型号多少百分比”。
