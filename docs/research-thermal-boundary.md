# 入口焓与控制体热边界

本地计算：2026-10-04；不刷新线上型号事实。研究对象是`prescribed_thermal_cycle_v1`合成算例，不是朱雀三号或长征十号乙的真实发动机。

结论：当前入口焓、密度是人为输入，不是有温压依据的液态物性。入口焓变化只改变维持给定热状态所需的热交换，不改变推力；密度变化通过泵功和分流影响性能。主室约193.65 MW的所需排热不能当作冷却系统设计负荷。

原输入见[合成算例](../cases/benchmarks/prescribed_cycle.ini)，显式假设见[循环说明](cycle-validation.md#synthetic-inputs)。生产数据固定于[NASA9清单](../data/thermo/manifest.json)，系数未改写；单物种软件参考见[保存值](../tests/reference/nasa9_cantera.json)。

实际运行C单物种查询`thermo CH4 298.15`与`thermo O2 298.15`，得到−4,650,159.637994和−0.000400 J/kg，与已有软件参考相符。输入焓分别差约+159.638和+0.000400 J/kg：它们接近298.15 K气态参考值，不是液态证据。当前物性温区从200 K开始，不应外推到低温液体。

NASA9系数的积分常数已包含形成焓。不能再加一次热值，也不能直接拼入其他物性库“任意零点”的液体焓。压力流功已在焓中；全局能量式不另加推力乘排气速度。泵功是内部轴能传递，不能在出口焓已升高后又重复作为控制体外部输入。

Q正号为流入该流体控制体的热量，负号为流出。入口焓改变时，给定温度/压力/元素库存并未改变，因而TP、涡轮、分流和喷管完全不变。泵出口焓随入口焓平移，解析关系是：

```text
ΔQ_generator = −mdot_branch_species × Δh_in
ΔQ_chamber   = −mdot_main_species   × Δh_in
ΔH_feed      = +mdot_total_species × Δh_in
```

例如燃料入口h升高100 kJ/kg：发生器Q降低0.033711 MW，主室Q降低2.239016 MW，总Q降低2.272727 MW，恰抵入口焓率的增加。推力不变说明模型固定了燃烧热状态，不说明真实发动机对入口状态不敏感。此实验没有解“改变入口焓后的新燃烧温度”。

恒密度泵采用`w_p=Δp/(rho·eta_p)`。只降低一侧密度10%，该泵轴功变为原来的1/0.9；涡轮给定状态及比功不变，新增泵负载提高支路流量。分流后的主室O/F改变，两路性能随之变化。这是输入假设的传播路径，不是低温物性、泵图谱或硬件升级预测。

## 193.65 MW为什么不是冷却负荷

控制体从两泵入口到两个喷管出口；辅助轴功与机械损失跨边界。主室/发生器Q是满足所给3300/1800 K状态的剩余能量，不是计算了壁面传热。全局残差接近零只证明按定义计账闭合，不能证明给定温度、入口物性或实际传热正确。

壁面冷却计算至少另需几何和沿程热流、燃气/冷却剂工况、换热与辐射模型、壁材与厚度、冷却通道及压损。净Q不提供局部峰值温度、热应力、烧蚀、寿命或侧载，因此不能拿该数直接定冷却流量或宣称再生冷却收益。当前也未模拟泵入口到主室间的冷却剂回路。

## 下一模型的输入与失败契约

先做独立的**给定入口焓绝热气相方法基准**，复用C的TP/HP与冻结喷管；不隐式改变现有给定温度循环。

| 必须说明的输入/边界 | 契约 |
|---|---|
| 反应物身份、元素库存与相态 | 首版仍仅CH₄/O₂气态；液态、煤油/替代物、凝聚相显式拒绝 |
| 入口焓基准 | 字段单位J/kg；采用同一固定NASA9的形成焓基准，与来源/版本同时记录 |
| 外部液体h/rho候选 | 先取得温度、压力、相态、物性版本与参考零点；未有证据，不接入液态计算 |
| 若以后转换外部焓 | 对每种推进剂建立有来源的同物理状态锚点：h_NASA = h_external + C_species；必须包括相变及压温差，不能随手给混合物加一个常数 |
| 热边界 | 给定TP与绝热HP互斥；HP用入口库存/焓率决定温度，Q=0是边界条件，不是倒算热量再贴“绝热” |
| 数值与失败 | 非有限输入、错相态、温区越界、无法夹逼、未收敛、残差超限分别显式失败；保持调用方输出，CLI失败不输出成功数据 |
| 固定面积与循环 | 单喷管固定面积不自动闭合泵功/分流；整机硬件、压损、回流及热闭合需新模型和单独参考 |

必须先比对“同NASA9气态温度输入”与“等价显式焓输入”的HP结果；再用固定CEA同条件气相HP、无反应解析极限和温区/失败反例核验。CEA同源数据库对照是实现校核，不是液态实验或整机验证。没有液体数据前，不为朱雀三号填液态入口；没有煤油组分/物性前，不把甲烷结果冒充长征十号乙结果。
