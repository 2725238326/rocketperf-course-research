## 2. 物理与数值方法

### 2.1 推力室与喷管

保留现有`ideal_constant_gamma_v1`，作为回归基准和课堂简化模型，不改变其已验证含义。

下一层选定为：**燃烧室平衡状态 + 温变热物性 + 冻结组分的准一维绝热喷管**。首版冻结位置固定在燃烧室出口，并在模型ID/结果中写明；不能与“喉部冻结”或“沿程化学平衡”混为一谈。

标量方程沿用有夹逼区间的二分法。先满足可解释和可靠收敛，再根据真实性能瓶颈考虑加速；不为算法名气先换求解器。当前过膨胀/分离限制保持，扩展适用域必须单独定义并验证。

### 2.2 热化学

选定 **NASA九系数热力多项式**表示温变热容、焓和熵；系数、形成焓、分子量、元素组成、温度区间及来源版本一同入库。具体数据文件的许可和物种有效区间必须逐项核对，不把代码仓库许可证自动套到任意外部数据。

平衡算法采用 **元素守恒约束下的Gibbs自由能最小化**。首版范围是选定C/H/O气相组分，不处理电离、凝聚相及沉积碳；具体组分集合根据参考算例和拟研究工况验证后冻结。不能把“仅气相”用于证明不结焦或不存在碳沉积。

数值路线：内层定温定压平衡，外层定压绝热焓平衡求燃温（HP问题）。小规模耦合方程采用阻尼Newton、残差缩放和线搜索；线性子问题用纯C带主元选取的LU求解。正量约束、收敛残差、温区越界和矩阵病态须有明确失败状态。

这些模块目前是**选定待实现**，没有以已有空气喷管测试冒充热化学验证。

### 2.3 整机循环

选定 **零维集总部件、稳态质量/能量/轴功率平衡**，围绕主室、泵、涡轮、支路和排气贡献建模。共享数值核心，不引入通用流程仿真平台。

先完成可识别的边界和守恒，再实现有数据支撑的耦合循环。液态推进剂入口焓、密度等先作为有来源的输入和适用范围，不在本次交付中重写完整真实流体物性库。型号循环不能从家族名称或新闻量级直接推定。

首版不做起动/关机的完整瞬态ODE模型，不从稳态曲线推导真实节流稳定区间或复用寿命。

### 2.4 不确定性与研究

选定可解释的参数扫描、局部敏感性和有依据的范围情景；这些研究数值由C模块产生。没有概率分布依据时不包装成置信区间。Python读取已保存的结果作绘图、排版和独立检查，不代替核心研究计算。

## 4. 数据和部署

- 单算例当前保留严格INI v1，不立即替换已通过验证的输入协议；复合化学/循环输入采用新schema/模型ID，设计完成后再上线。
- 参数/来源登记采用JSON，字段包含对象/批次、单位、工况、主室/整机边界、事实/派生/假设/未知和引用。
- NASA9内部系数数据采用版本化固定列TSV，每个温区单独一行，伴随JSON来源/单位/温区manifest；具体列定义由数据契约任务实现前冻结。格式转换可以使用工具，物性和性能求解必须在C中执行。
- 核心运行依赖限C运行库/数学库及随包提供的必要数据；对照软件和绘图环境不混入最终exe的物理依赖。
- 最终发布为Windows x64可运行程序、算例/数据、中文说明和可复现命令的压缩包；单独提交源码、研究报告和PPT。不承诺一个exe包含全部数据或依赖，必须在干净目录复测。
- 数据量和协作规模目前适合文件/Git；不引入SQLite、PostgreSQL或服务端API。

## 5. 界面和图表

控制台承担运行入口，离线HTML承担结果阅读；已有SVG/Mermaid架构图继续维护。科学图表统一由Matplotlib从保存的结果生成，优先SVG，另导出高分辨率PNG。

不引入React/Vue、Electron、Qt、Flask/FastAPI或Web服务；不把界面搭建变成主任务。离线报告没有服务器、账号和部署需求。Matplotlib仅用于离线工具，默认质量检查不新增此依赖，绘图模块实装后增加相应验证。
