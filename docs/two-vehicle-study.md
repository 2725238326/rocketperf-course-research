# 两型一、二级：证据与计算落点

本地整理：2026-10-05。两型网页的既有核验截止为2026-10-03，本轮只复读保存原文，不更新在线事实。课程任务是调查工作方案、计算性能、研究带计算的改进；不是只写两型新闻，也不是用软件测试数量证明真实发动机性能。

现在可以完成有来源的构型比较，以及有明确假设、Windows 可复跑的 C17 方法研究。尚不能给出四个级段的真实绝对比冲/推力排名：必要的型号输入没有公开到能建立一致性能卡的程度，长十乙一级的煤油也没有进入现有燃烧模型。机器可读对应在[四对象映射](../data/parameters/assignment_case_map.json)，不是供求解器直接装载的型号输入。

## 2. 事实、派生、假设、未知各做什么

事实由[baseline](../data/parameters/baseline.json)及原文支持。派生示例是12A产品栏目84.6 tf换算约829.64 kN；它仍属于产品栏目，不能与7542 kN整箭值平均、拆分后反证单机模型。只要工况和对象不同，数字相近也不是同一个参考点。

[assumptions](../data/parameters/assumptions.json)的7 MPa/面积比18是早期定比热方法包络，不是两型室压证据，也不能迁移成新的HP默认参数。现有连续液体算例则在自己的归档中声明Pc=10 MPa、At=0.01 m²、CH₄=120 K、O₂=100 K、两路压力10 MPa、O/F=3.4、面积比10、真空。这些值与型号没有参数绑定。

未知量不是全部同等阻塞：

| 欲回答的问题 | 最少还缺什么 | 缺失时怎样处理 |
|---|---|---|
| 真实甲烷燃烧室温度、c* | 同批次Pc、主室O/F、入口温压/化学焓及纯度、适当产物/相态与损失边界 | 只做带ID的研究假设，不贴型号性能标签 |
| 真实单机推力、流量 | 以上条件加At、面积比、背压及主室/整机流量边界 | 不能用公开总推力唯一反演性能卡，也不能随意分摊 |
| 真实发动机比冲 | 主室与支路流量/推力、泵/涡轮/回流组成和能量边界 | 单主喷管比冲不当整机比冲；不由守恒自证未知循环正确 |
| 煤油燃烧和膨胀 | 燃料组成或说明适用范围的替代物、化学焓基准、物性与产物/凝聚相参考 | NIST候选只用于方法选型；CH₄模型不给煤油级段代算 |
| 回收消耗、载荷收益、复用寿命 | 级段质量/时间历程、节流/起动、硬件/冷却/寿命数据 | 保留工作能力事实，不给无依据的成本或寿命百分比 |

## 3. 已有计算怎样服务作业

甲烷级段可以关联[连续入口HP与固定喷管](liquid-combustion-validation.md)：纯CH₄/O₂单相查表化学焓与元素库存，C17求九气相绝热燃烧室，再求燃烧室冻结喷管。基线模型温度3602.756 K、c*1811.000 m/s、流量55.218125 kg/s、推力173.721212 kN、比冲320.811939 s。47次C运行和18次CEA显式焓对照固定在[归档](../results/validation/liquid_combustion_v1/manifest.json)。这些数字只能放在“假设方法算例”栏。

入口压力在这里选择查表状态，并没有求贮箱—泵—喷注器路径；入口压力等于/低于室压的焓敏感性点不能宣称供给系统可工作。单喷管不重新闭合轴功和分流。两边使用同源物性与受限物种，CEA对照属于软件方法核验，不是独立实验验证。

煤油一级已有[固定RP-1方法研究](../调研/专题/RES-008_煤油计算边界.md)及[纯C公共接口](kerosene-validation.md)：方法限定10 MPa、O/F=2.2–4.0和指定反应物温度，七点燃烧室/冻结喷管参考已保存。它未绑定长十乙真实燃料。富燃料失败和凝聚碳说明九气相不能覆盖全部煤油条件；国产煤油批次、连续物性与真实发动机输入仍缺。

## 4. 现有同条件改进研究

### 喷管膨胀与环境压力

[合成外排研究](improvement-analysis.md)在同一100 kg/s、给定主室5 MPa/3300 K和支路边界下，面积比10→20→40，真空合成比冲302.095→315.143→325.508 s；出口面积0.338897→0.677795→1.355590 m²。收益同时伴随尺寸增长；没有算质量、长度、冷却、侧载和寿命。

环境压力升到5 kPa时，同几何比冲分别下降1.748、3.475、6.931 s。大喷管并非所有环境下都优；超域点不作零推力、不解释为已经分离。这条方法对应一级/二级不同环境任务，但不是两型的面积比改装量。煤油级段只能引用压力推力和几何逻辑，不继承甲烷数值。

### 支路排气与发动机边界

同一合成循环把支路轴向投影由0改为1，推力增加1406.887 N、比冲增加1.434626 s；未改变支路流量/轴功/热状态。它解释发动机计账不能漏外排流量和推力；未算重新布管、排气干扰与热防护代价。历史TQ-15A排气进入延伸段有研究动机，但现有“两路独立喷管”不是延伸段混合流模型，更不是主室补燃。

### 固定几何液体入口响应

在连续液体基线保持Pc/At/面积比/真空，CH₄升至140 K、O₂升至110 K，比冲增加0.280323 s，推力反而减少9.718 N。`mdot=Pc×At/c*`使通量降低；评价改进不能只看比冲。该点不含预热器功耗、压损或相变，不能推荐真实预热装置。面积比10→40的单喷管比冲增益24.656072 s也只是在出口面积0.1→0.4 m²下的理想几何比较。

这三组研究回答REQ-03的收益、代价和适用条件，不形成真实型号优劣排名。原循环扫描按给定流量重新定尺寸；连续入口算例固定喉面积。两者边界不同，不串接成一条实际调节曲线。

## 5. 继续做什么

优先补煤油的可计算边界和参考，不继续堆甲烷扫描；若公开资料仍不能绑定国产煤油，完成具名替代物的方法研究并明确保留型号不可算结论。再审泵后入口、支路/回流热与组成边界，有同条件参考才实现循环扩展。现有程序与资料足以解释部分课堂性能关系，但真实煤油一级、整机闭合和型号独立验证仍未完成。
