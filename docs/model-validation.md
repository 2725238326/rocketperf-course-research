# 分层验证与误差分析

版本：VAL-001 v0.1；验证截止：2026-10-02

本文件回答“结果为什么可信、可信到哪一步”，并把三类误差分开：代码实现误差、模型差异、输入/数据库不确定性。当前验证对象是 `ideal_constant_gamma_v1` 与其 S1 扫描入口，不是任何真实发动机。

## 1. 验证层次

| 层次 | 参考或检查 | 当前证据 | 可以支持的结论 |
|---|---|---|---|
| V0 协议 | 输入字段、状态码、单点失败不改输出、扫描逐点状态、JSON检查 | `tests/test_adapters.c`、`tests/test_cli.py`、`tests/test_runner.py` | 软件边界和运行记录可复现 |
| V1 解析解 | `gamma=1.4, Me=2, Ae/At=27/16` 的闭式关系 | `tests/reference/air_mach2.json`、`docs/benchmarks.md` | 求根和 L0 公式实现达到给定数值容差 |
| V2 物理不变量 | 连续方程、总焓、面积缩放、背压推力差 | `tests/test_core.c` 的 42 组组合及 S1 网格测试 | 在模型假设内守恒和尺度关系成立 |
| V3 适用域 | `gamma`、面积比、正量、背压、非有限值、预算耗尽 | C 核心失败路径和 CLI 越域测试 | 越界不会被静默当作成功结果 |

## 2. 代码实现误差

代码误差指在模型和输入固定时，程序相对于独立数学参考的偏差。当前可量化边界如下：

- 面积—Mach 方程使用夹逼二分，成功返回前要求相对面积残差不超过 `1e-8`；解析 Mach 2、Mach 3、`gamma=5/3, M=2` 和声速出口均有回归检查。
- Mach 2 参考结果由已知 `Me=2` 直接代入闭式公式得到，未调用待测反解程序；核心测试对主要输出使用约 `1e-10` 相对容差。
- 42 组 `gamma/面积比` 组合检查出口连续方程和总焓；S1 扫描额外检查背压变化只改变压力推力项，越域点保留状态。
- 单点求解若预算耗尽、结果非有限或残差超限，不修改原结果；扫描保留逐点诊断，数值失败让CLI返回非零。扫描函数返回正常只表示完成网格评估。

这些数值容差是软件回归门槛，不应解释成真实发动机测量不确定度。

## 3. 模型差异

模型差异是理想定比热、准一维、稳态、等熵、无损失模型与真实物理之间的差距。当前未量化，也不能从本项目的解析测试中推断：

- 工质化学平衡、温变比热、解离和冻结流；
- 边界层、热损失、喷管效率、激波、分离和非均匀流；
- 泵、涡轮、燃气发生器、喷注器、冷却支路和控制器；
- 起动/关机瞬态、节流稳定性、结构强度、寿命和重复使用。

所以 L0/S1 的推力和比冲只能作为同一教学假设下的相对趋势。进入 L1 前，必须用固定版本的 NASA9 数据和独立物性/CEA 小算例量化热化学差异；进入 L2 前，必须用质量、能量和轴功率残差量化循环边界差异。未完成这些步骤时，不允许给真实型号贴绝对性能标签。

## 4. 输入与数据库不确定性

`data/parameters/baseline.json` 将字段分成 `fact`、`derived`、`synthetic_benchmark` 和 `assumption`，并列出真实发动机缺失字段。当前 ZQ-3/CZ-10B 公开资料可以支持构型或推进剂背景，但不能直接提供所有求解器所需的室压、面积比、O/F、工况比冲和流量图。

因此：

1. 缺失真实字段不进入数值求解器；
2. 研究假设必须单独给出范围、理由和模型ID，并在结果中显示；
3. 同系列产品页、不同批次或二手摘要不能拼成某次飞行的“真实参数集”；
4. 不确定性分析应先扫描假设包络，再讨论敏感性，不得用一个未经证据支持的点值掩盖未知。

## 5. S1 可报告结论与禁用结论

在固定教学输入和 L0 适用域内，可以报告：面积比改变出口 Mach/压力/速度；环境压力升高会降低压力推力项；当背压高于理想出口压力时，当前模型只报告 `out_of_domain`，不声称给出了分离流结果。可以比较同一输入包下的 `F`、`CF` 和 `Isp` 趋势。

不能报告：某真实发动机的实测推力/比冲、海平面分离高度、节流可靠性、冷却裕度、循环功率、结构安全系数或回收寿命。任何这类结论都需要新的数据契约、物理模型和独立验证。
