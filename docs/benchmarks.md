# 首个基准与适用域

## mach2

输入是人为定义的**定比热理想空气教学算例**：`gamma=7/5`，`R=287 J/(kg·K)`，储室总温300K、总压1MPa、喉部面积0.001m²，出口面积比27/16，真空背压。它不代表甲烷/煤油燃烧产物，也不代表任何真实发动机。

已知的准一维等熵关系为：

```text
Ae/At = (1/Me) * [2/(gamma+1) * (1+(gamma-1)*Me²/2)]^((gamma+1)/(2*(gamma-1)))
Te/T0 = 1 / (1+(gamma-1)*Me²/2)
pe/p0 = (Te/T0)^(gamma/(gamma-1))
ve = Me * sqrt(gamma * R * Te)
c* = sqrt(R*T0/gamma) * [(gamma+1)/2]^((gamma+1)/(2*(gamma-1)))
mdot = p0*At/c*
F = mdot*ve + (pe-pa)*Ae
CF = F/(p0*At)
Isp_s = F/(mdot*g0), g0=9.80665 m/s²
```

以`Me=2`和`gamma=7/5`直接代入面积式，严格得到`Ae/At=27/16=1.6875`。因此出口马赫数的参考值预先已知，不来自待测二分求根程序。其余期望值由上述已知Me的闭式关系以Python Decimal 50位精度计算，再舍入为double存入`tests/reference/air_mach2.json`。

## 额外独立关系

- `gamma=7/5, Me=3`时，面积比为`343/81`。
- `gamma=5/3, Me=2`时，面积比为`49/32`。
- 面积比1时应得到声速喉部出口Me=1。
- 同一几何/储室条件将背压从0改为100000Pa，推力应减少`pa*Ae=168.75N`，而模型中的质量流量不变。
- 喉部面积加倍、面积比不变时，推力和流量加倍，比冲与CF不变。
- 在42组gamma/面积比组合下，检查出口连续方程与总焓守恒；这类关系是补充实现检查，不能替代独立参考。

## 适用范围

数值接口限制`1<gamma<=2`、`1<=Ae/At<=10000`，温度/压力/气体常数/喉部面积为有限正数，背压有限且非负。模型只接受背压不大于理想出口压力（允许比较中的极小相对舍入误差）。尚未建模化学反应、温变性质、黏性/热损失、激波、分离、冷却、循环、节流稳定性和寿命。

公开真实型号数据不能直接填入该模型就被称作“真实发动机仿真”。扩展模型必须新增数据依据和适用域验证。
