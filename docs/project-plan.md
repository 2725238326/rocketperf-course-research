# 研究与交付规划

维护日期：2026-10-06。课程展示：2026-10-16，周五第3–5节。老师要求以[存档](../作业要求/大作业1_要求存档.md)为准；以下是项目实施安排，实际任务状态由[worknow](../worknow.md)生成。

## 研究目标

调查朱雀三号与长征十号乙动力系统，用C程序计算性能关系，再以同条件计算分析优缺点和改进方案。四个对象为朱雀三号遥一一/二级、长十乙首飞一/二级，分别保留批次、级段和工况。

| 研究路径 | 应回答的问题 | 已有产物与继续条件 |
|---|---|---|
| 工作方案 | 各级使用什么推进剂、发动机配置与工作能力？ | [四级段研究](two-vehicle-study.md)；沿已有缺口补原文，不跨批次拼性能卡 |
| 性能计算 | 温度、c*、流量、推力和比冲如何由输入产生？ | [甲烷液体HP/喷管](liquid-combustion-validation.md)、[固定RP-1方法](../调研/专题/RES-008_煤油计算边界.md)；固定反应物、产物和输入基准后再扩接口 |
| 改进分析 | 哪些变化有收益，代价和限制是什么？ | [喷管/支路研究](improvement-analysis.md)、[入口响应](adiabatic-inlet-study.md)；给定循环和单喷管结果按各自边界解释 |

真实构型比较呈现实际方案差异；同条件方法算例研究某个因素的影响。缺失尺度时比较无量纲系数或比冲；缺失组成/入口/循环时保留不可计算项。公开额定值用于校准后不能再作为独立验证点。

## 计算路线

C17核心采用零维热化学、准一维冻结喷管和稳态部件计账。Python负责构建、验证、归档与绘图。工具和边界见[技术选型](technology-stack.md)，依赖与模块见[架构](architecture/README.md)。

保留定比热课堂基准；已实现NASA9、九气相TP/HP、固定液态甲烷/氧锚点、连续单相甲烷/氧查表和固定面积喷管。固定RP-1通过研究驱动复用内部库存求解器，富燃料条件有拒绝/凝聚碳证据，公开CLI接口需继续验证。循环目前给定热状态，回流/喷注/泵后状态仍缺契约和参考。

公式、单位、守恒、失败行为和参考对照共同支撑验证。相同物性库的软件差异与硬件误差分别说明；不能由平衡燃烧或稳态曲线推导真实寿命、节流稳定性或多次起动能力。

## 实施顺序

1. 固定可汇报的方法结果、失败点和来源，将其关联到课程三条研究路径。
2. 完成RP-1入口的内部点参考和公开接口；继续核对甲烷泵后温压、喷注压差与焓/轴功边界。若输入仍缺，保持条件性方法算例。
3. 从已有喷管膨胀/背压和支路排气结果中选定改进主线，整理收益、尺寸代价和输入响应。新增模型须能改变该问题的回答。
4. 输入、计算与结论稳定后，准备发布版、报告和PPT，执行接收者复跑与展示验收。

10月12日建议固定课程使用的主要模型和算例版本；10月13–15日用于四项交付和复跑。日期是交付安排，不能迫使未验证模型进入课程结论。当前最终报告/PPT保持后置，任务选择不由旧日程触发。
