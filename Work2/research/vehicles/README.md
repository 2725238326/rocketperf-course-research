## 来源如何读

完整URL、原始路径、获取时间和SHA256统一在[来源索引](../data/source-index.json)，不另复制一套来源数据库。正文用稳定来源ID定位，结构化观察还给短引文和段落。资料有三类：首轮已核的W2-P01–07；本批HTTP获取W2-V01–10；原址复用的历史W2-VL01–12。历史复用保留2026-09-29或10-06的原获取日期，本次核读不自动宣称已重新在线获取。

| 来源ID | 原文/核读范围 | 主要限制 |
|---|---|---|
| W2-P01 / P06 | 蓝箭中英文产品栏，ZQ-3和TQ-12A分别核读 | 产品页无发布日期；英文页没有同一ZQ-3栏目，不拼成完整飞行输入 |
| W2-P02 / P05 / P07 | 2025-12-03遥一、2026-08-19遥二、2025-10-20阶段一公告正文 | 不自动补未给出的子型、工况或后续复飞 |
| W2-P03 / P04 | 长十乙院方产品与2026-07-15发动机研制报道 | 吨级与主室精确参数分开 |
| W2-V01 / V02 | 蓝箭大事记、技术路线及基础设施 | 企业自述/索引；不足以支持具体飞行子型配置 |
| W2-V03 | 下载页HTML模板 | 动态列表未取得，不是已下载技术手册 |
| W2-V04 / V05 | 海上回收记、娄路亮原始采访正文 | 工程叙述，非测量数据集或寿命试验报告 |
| W2-V06 / V07 | DOI重定向页、出版者HTTP403 | 未取得论文摘要/全文；重定向HTTP200不算论文可得 |
| W2-V08 / V09 / V10 | 2024两次VTVL、2025百台发动机及B型地面试验原文 | 试验平台、系列累计与飞行装机分别使用 |

| W2-VL04 / VL05 | Crossref论文元数据、载人航天网标题/作者/摘要 | 分别仅元数据与摘要，均未取得全文 |
| W2-VL06 / VL07 | 2025九机地面试车；2023型号发布的制造商转登报道 | 地面/规划与实际首飞分开 |
| W2-VL09 / VL10 | 六院140吨级开式试验产品报道、新华社相关报道 | 非两个独立台架数据集；试验产品与飞行子型未闭合 |
| W2-VL11 / VL12 | 长十二YF-100K报道、长十系列七机系留试验报道 | 专门保留近名/近族对象，防止误当乙型装机证据 |

## 本批阅读结果的使用

Grok三个Topic依次先DryRun：朱雀深研请求无搜索轨迹；长十乙与朱雀聚焦来源请求分别有12、8条结构化调用记录。原文另行HTTP核验。有轨迹的长十乙回答仍出现已核原文未支持的“1台YF-219”叙述，已排除为型号事实，仅留待核线索；这不是对该型号关系的反证。

精选数据由`python tools/work2_vehicle_data.py`生成，`--check`检查漂移与引文定位；根统一质量同时核验原件哈希、来源可用/核读状态和未知值。新增批次有独立成员范围，首轮coverage继续固定其46条记录，避免把本轮采集倒记成首轮完成。

继续深化优先处理会改变模型选择或结论的证据：同批入口/主室/几何、甲烷二级精确装机/循环、原始技术论文全文、真实复飞与后检数据。通稿重复和企业宣传排名不作为深度指标。
