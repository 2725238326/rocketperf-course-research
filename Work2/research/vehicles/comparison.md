# 两型同口径比较与计算落点

核读截止2026-10-24。对比对象先选朱雀三号遥一/遥二、长十乙首飞和各自产品/设计状态；不能将一个对象的设计目标与另一个对象的飞行结果放进同一性能排名。原文定位与数字来源见[两型专题入口](README.md)，本文不产生新数值求解或真实性能卡。

## 1. 可以支持的比较

| 维度 | 朱雀三号 | 长征十号乙 | 比较应保留的条件 |
|---|---|---|---|
| 构型/箭径 | 遥一单芯两级，4.5m | 首飞两级，5m | 两份明确飞行公告，不能解释成同级质量或效率差异 |
| 推进剂 | 遥一两级液氧甲烷 | 首飞一级液氧煤油，二级液氧甲烷 | 煤油批次未知；推进剂不同与循环不同的效应不能混为一个因素 |
| 一级发动机 | 遥一9台TQ-12A；无日期产品页为9台12B | 首飞采访7台液发100系列，5摇摆2固定 | 型号/版本和具体后缀证据分别保留 |
| 二级发动机 | 遥一1台TQ-15A；产品页15B；遥二具体后缀未给 | 首飞团队文章140吨级甲烷，确切型号/台数未闭合 | 不据量级推出型号、循环和精确性能 |
| 回收方式 | 遥二陆地支腿软着陆成功 | 首飞海上平台网系捕获成功 | 不直接推断系统成本、维护工时或复用寿命优劣 |
| 复用实证 | VTVL-1原文支持同试验箭再飞；轨道级一级回收与复飞分开 | 首飞一级捕获与计划复飞分开 | 试验平台复用、轨道复飞、设计寿命是不同指标 |
| 公开运力 | 当前产品450km LEO：一次性21.3t、航区18.3t、返场12.5t | 采访回收状态200km16t；900km/50°11t | 轨道/倾角/回收条件不齐，不能据18.3>16判定型号总体优劣 |
| 热力可算性 | 甲烷方法可做条件研究，主室/入口/几何缺口仍在 | 煤油与甲烷分别建入口，二级架构保留待判 | 数值可计算与真实输入可得性分别说明 |

## 2. 六组需要保留的差异与冲突

1. **76.6m与66.1m：**早期/当前产品与遥一飞行状态分开；不能取平均，更不能据当前页反推遥二。
2. **60%–110%与60%–100%：**TQ-15A不同年份说明，参考推力/工况与技术变化未查清；保留原文。
3. **超10万秒与6.8万秒：**前者为系列地面验证，后者限定湖州大推力发动机；统计母体不齐，不据此计算寿命或失败概率。
4. **约63m/63.6m、约890/约900吨：**近似精度/叙述口径分别记录；不制造精确派生值。
5. **地面140吨级开式与飞行二级140吨级：**存在产品级线索，尚无精确子型/状态直接桥接；循环结论保持边界。
6. **VTVL的45%–110%与45%–111%：**原试验日期分别保留，不扩成所有TQ家族共同范围。

结构化冲突K01–K06见[证据数据](../data/vehicle-evidence-v1.json)。有些差异可以由版本或精度区分，有些仍需原始定义；不能将“可能口径不同”写成已经查明原因。

## 3. 数据详尽程度的三层判断

| 层次 | 本批能做到什么 | 仍需什么 |
|---|---|---|
| 整箭/事件 | 明确选定版本、动力组合、主要验证事件与结果，追到制造商/院方/原始采访 | 更完整的批次事件登记及新事件原文；不作全网穷尽声明 |
| 发动机/系统 | 区分家族、历史子型、地面试验、已证实装机、供给和回收接口线索 | 装机桥接、冷却/泵图谱/损失、真实动态与寿命数据 |
| 热力数值 | 逐项标明产品观察与同批未知，界定可做的条件研究 | 同批Pc、主室O/F、两路入口、几何、整机边界及不确定性 |

三层分别深入。上层材料增加并不必然补齐下层数值；下层未知也不阻止已经明确的事实和方法研究。

## 4. 对研究问题与C模型的影响

| 研究问题 | 可以开展的工作 | 结果不能外推到哪里 |
|---|---|---|
| 同模型C实现是否正确 | 固定物种、物性、入口与参考，验证TP/HP/冻结喷管及失败 | 同源数据库吻合不是两型实机准确度 |
| 推进剂与入口有何影响 | 声明甲烷与指定煤油替代物，各自在可用入口域比较 | 不能归因为真实甲烷/国产煤油发动机优劣 |
| 开式/补燃对计账有何影响 | 固定共同条件，分开主室/支路、轴功和焓流的条件模型 | 不能将待判二级拓扑定成实机架构 |
| 缺少哪些输入最影响结论 | 用有依据的范围做敏感性，报告假设变化是否改变回答 | 不能由公开整箭推力唯一辨识整套主室/循环参数 |
| 如何解释回收需求 | 引用真实验证事件说明节流/多次起动/环境的重要性 | 当前稳态热力计算不预测着陆成功、瞬态点火可靠性或复用寿命 |

## 5. 下一轮资料优先级与停止理由

**优先：**能改变模型选择或减少主导输入不确定性的原文。包括：二级确切装机与循环、主室/整机O/F定义、真实入口焓及几何、作者技术论文全文、回收后检测和同一级复飞记录。论文的来源、年份、对象和全文可得性先核验，再摘参数。

**继续但不阻塞基线：**VTVL与轨道级验证链的补全、历史型号关系、试验统计口径、产品规范变化原因。保持同一主索引和原件身份，不重复复制旧材料。

**停止低增量扩收：**同一通稿的更多转载、无对象/工况的推力数字、未披露定义的排名、由照片比例猜测并当直接数据。对本批出版者403、动态列表和无轨迹请求保留限制，等待有效新来源，不无限重试。

本专题回答“目前可以查到并核实多细、哪些还查不清”。更详尽的公开研究依赖后续增量证据；不预设未公开资料必能获得，也不让参数缺口成为停止独立C验证的理由。
