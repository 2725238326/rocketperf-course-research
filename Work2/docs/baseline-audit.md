# 作业一基线继承审查入口

2026-10-23完成的是源码定位、历史证据身份检查和继承规划；WBASE-001承担本阶段新的系统复跑和误差审查。不能将“有旧测试”直接升级成“满足作业二全部验证”。

## 已核实的继承事实

[equilibrium.c](../../src/thermo/equilibrium.c)头注释与HP实现表明：内层是九种理想CHO气体的Gibbs/元素势法，四个未知量包括三个元素势与总摩尔数对数，以带回溯的阻尼Newton求TP解；HP外层夹逼温度，用Illinois假位法，必要时试中点。热启动种子来自较近的已收敛端点。

因此，“伊利诺伊那个方法”在现有仓库有明确对应：**Illinois是HP外层的一维求根策略，化学平衡基础是内层Gibbs/元素势条件。** 它不是另一套化学平衡理论，也不能独自说明真实发动机精度。旧[工程证据manifest](../../results/research/engineering_evidence_20261014/manifest.json)记录单机CPU比较及固定基线提交；旧速度数字只适用于当时数据和机器，本阶段须重新量测。

源码默认平衡容差1e-10、HP焓容差0.01 J/kg，温度夹逼1000–6000 K；声明的压力范围100 Pa–1 GPa。它们是实现准入/停止参数，不等于整个范围都有足够独立参考覆盖，更不等于真实模型精度。CHO库存接口要求C/H/O均为正且描述固定化学质量基准的一公斤；不能据此宣称支持任意含零元素的体系。

代码对收敛后的凝聚碳风险作guard，不求解含凝相的完整平衡；暂态温度端点与最终可用状态分别检查。范围及物种缺失须在新验证协议中明确。

## WBASE-001的具体审查工作

1. 固定当前源码、编译器、参数和参考身份；定义哪些是既有回归、哪些是新验证。
2. 将TP、HP、入口焓和喷管分层。为每层列输入域、方程、残差、停止/拒绝条件；检查HP夹逼、内层失败和外层误差预算的传播。
3. 选择代表域内、域边界和已知拒绝案例；避免只有中心工况。先解释阈值依据和参考有效位数，再比较。
4. 分别做同物种/同数据的实现对照与物种/相态/冻结假设比较。将来源不足和参考同源明确列出。
5. 测量TP调用数、外层迭代、失败率和端到端成本，保存成功/失败原始输出与manifest。旧计时不复制为本次证据。
6. 写出保留、需修正、需新增和暂缓项；证据没有闭合的能力不进入正式创新主张。

本批未改C生产代码，未承诺完整CEA重写、完整输运性质或通用多相求解器。是否扩展以教师目标、误差预算和实测瓶颈共同决定。
