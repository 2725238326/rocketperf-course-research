# 如何判断成果好

这里是项目自定的验收框架，依据教师要求、基本守恒与可复算原则制定。行业统一数值阈值、当前领先排名和特定论文结论尚未核实，不能把本框架称为认证标准。课程完成、工程可信和研究贡献分别评价，不用加权总分掩盖硬性缺项。

## 三层目标

| 层级 | 必须回答的问题 | 放行证据 |
|---|---|---|
| 课程合格且完整 | 教师要求是否全部闭合，能否说明方法、结果和个人贡献？ | [W2-R01–13](requirements.md)实际产物定位；四件套；10分钟演练；完整性审核事实 |
| 可信计算与工程 | 解的是什么问题，何时正确，误差多大，什么时候应拒绝？ | 方程/输入身份、验证矩阵、失败边界、重建与结果复跑、误差和计时档案 |
| 有证据的研究贡献 | 相对最强适用基线究竟改善什么，代价和局限是什么？ | 预注册指标、同条件比较、消融/反例、域外失败、全部成本和负面结果 |

目前只能说治理与研究起点已经建立；后两层的具体成果需要后续实验。公开基准和最新竞争方法不足时不作SOTA声明。

## 七项不可互相抵消的检查

| 维度 | 需要留下的证据 | 不能算通过的情形 |
|---|---|---|
| 模型和数据身份 | 元素/物种/相态、数据版本与系数区间、单位/参考态、入口状态、控制体、冻结点和适用域 | 给定燃温当绝热求解；RP-1当国产煤油；模型值当实测 |
| 数学与物理一致性 | 元素库存、非负性/归一化、压力/状态关系、平衡条件、焓闭合；喷管假设适用时检查熵/能量/流量 | 只看温度或比冲合理；仅迭代步长变小 |
| 数值验证 | 解析/手算极限、不同实现、容差收敛、失败/边界、物性断点；对参考打印精度说明 | 用同一恒等式回代验证；默认两软件同源数据是独立物理证据 |
| 工程可靠 | 清晰API/失败契约、固定构建、警告与适用动态检查、回归、成功和拒绝复跑 | 编译成功或一次正常运行代替可靠性 |
| 效率 | 同输入/容差/成功率/硬件；预热、重复、线程、CPU墙钟及端到端成本 | 只报最佳点/核函数时间；忽略失败、数据生成和训练 |
| 研究贡献 | 问题、竞争方法、可证伪假设、消融、最坏情形和停止条件 | 算法新颖、代码量多、使用A100或技术组合即称创新 |
| 复现与展示 | 输入→构建→原始输出→分析→图表→结论的版本链；图单位/图例/有效位数及可重建数据 | 手改图中数字、结果只留截图、未跑却写已完成 |

## 指标怎样定义

每项实验在运行前冻结量纲和尺度。建议记录元素残差 `max_e |(A n)_e-b_e|/s_e`、焓残差 `|h-h_in|`（J/kg及预先约定的相对尺度）、归一化误差、非负性、平衡驻点/反应亲和条件；`s_e`和近零组分的绝对误差地板必须说明，不能除以接近零的参考量夸大或掩盖误差。

温度、组分、c*、CF、有效排气速度或Isp等按具体任务选择。每个量给绝对误差、相对误差（分母有意义时）、最大值及分位数；Isp的秒与m/s必须明确且用相同g0换算。报告总尝试数、预期域内数、成功数、正确拒绝数、异常失败数和漏检数。

数值容差、参考误差和模型误差分别列预算：内层平衡容差、外层HP焓容差、物性拟合/插值、物种截断、冻结假设、入口参数和真实燃料不确定性。当前源码默认 `equilibrium_tolerance=1e-10`、HP焓容差0.01 J/kg是实现参数，**不是经证明的整机准确度**。WBASE/WREF任务应据量级和参考精度确定各检查阈值，再开实验，不凭空设统一百分比。

比较分两种：**同物种/同相态/同数据**评估实现误差；**扩充物种或改变物理假设**评估模型差异。二者不可混成“算法误差”。有实验时另记录仪器、工况与测量不确定性；没有实验就明确缺这一层。

## AI与性能改进的附加门槛

先量测基线，确定问题是时间、失败率、模型不足还是输入证据不足。候选至少对比传统数值、热启动/插值等简单方法。学习型预测优先考虑初值建议、域识别或带回退的辅助，不未经检验直接替代物理解。

训练/调参和最终测试按连续工况块或输入身份隔离，避免邻近扫描点随机分割导致泄漏；记录域边界及域外输入、守恒投影/校正成本、参考生成成本、训练成本、推理、回退率和部署成本。消融区分数据、物理约束、网络结构和回退带来的收益。

若高吞吐收益不足以摊销训练/生成成本，或失败/域外错误增加，复杂路线停止。CPU与A100比较须记录精度、批量和传输；“训练可用GPU”不等于最终C程序满足部署约束。没有核实硬件和访问前不称资源已可用。

## 放行顺序

要求/输入身份 → 数学与物理契约 → 验证协议与基准 → 软件质量 → 小实验与路线取舍 → 正式比较 → 四项交付。每一关允许记录未知和失败；后关不能用漂亮图表补偿前关缺证据。正式机械验收仍走统一质量入口，语义验收由负责人解释覆盖范围。
