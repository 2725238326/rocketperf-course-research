# 教师要求与需求追踪

主依据：[作业要求.png](../作业要求.png)，图中日期2026.10.19。2026-10-23人工核读，亦与课程“第4、5节”PDF第49页核对。以下“原文”保持要求含义及措辞，排版换行合并；计划项是项目安排，不是教师附加条款。

## 教师原文

**题目要求：**基于化学平衡常数法或最小吉布斯自由能法，采用C语言编程实现重复使用运载火箭朱雀三号和长征十号乙发动机热力性能参数的计算。调研相关文献，结合大作业1，进一步研究朱雀三号和长征十号乙发动机的性能。

**程序要求：**程序发布版可以是控制台形式的或带用户友好界面形式等的多种方式，同学根据自己编程能力和喜好自定，重在掌握计算方法和获得合理计算结果。

**报告要求：**撰写包括研究目标、计算方法、参数确定、程序设计、程序说明、案例结果、验证与分析、研究特色、结论与感悟、参考文献、组员协作分工等内容的研究报告。

**团队要求：**组长是项目负责人，负责分解任务、组织推进团队协作，人人有贡献（编程、算法、资料、报告、PPT、数据整理、结果分析等等）。

**汇报要求：**12月5日（周五）3–5节课上用PPT展示汇报研究成果。每组汇报10分钟，师生提问5分钟。

**作业提交：**课堂展示当天由组长上交完整作业电子版材料（主要包括程序源代码、程序发布版、展示PPT、作业报告等4项内容），并由助教审核作业的完整性。

**成绩评定：**评委和同学现场打分与提交的作业质量综合评定，小组成绩就是组员的成绩。

## 未明确与冲突

- **日期/星期冲突：**资料写“12月5日（周五）”，按2026年12月5日核算为周六。暂以原日期设内部准备线，待课程新通知确定；不擅改为12月4日或其他年份。见[U-001](review.md)。
- 未见报告页数、模板、源码规模、强制GUI、GPU、神经网络、双方法实现、必须SOTA或具体误差阈值要求。
- 原图没有逐项评分权重；[项目质量标准](quality-standard.md)属于自定工作标准，不能称行业统一门槛或教师评分细则。
- “进一步研究”保留技术选择空间，最终选题应回到有证据的瓶颈与可检验贡献。具体子型/工况资料不足时仍可做有明确身份的条件研究，不能宣称完成真实性能卡。

## 用户愿景与项目建议

用户愿景：高质量、深入学习、C工程提升、探索AI/深度学习/RL/自进化、考虑已有A100、形成有价值的创新和高质量图表。这些不是必须全部实现的清单。“jev”的确切含义未知。

项目建议：可靠基线、误差预算、物种/相态与模型假设比较、健壮性和端到端成本优先；通过小实验再选择创新路线。具体依据见[研究规划](research-plan.md)及[提示词审阅](prompt-review.md)。
