# 选定结果档案

此处保存正式选定的验证/研究版本；当前没有本阶段新的热力计算结果。临时运行、PDF抽取/渲染及构建位于根 `build/work2/`，不进Git。

一个结果版本至少保存：研究问题及协议版本、输入及来源/假设、模型/数据/源码身份、编译器/硬件/命令、stdout/stderr、成功与失败结果、单位/误差/计时分析、文件SHA256和manifest。计算结果与外部参考分文件保留，禁止手动改原始数值。

使用唯一版本目录和RunId，失败也记录，不覆盖旧版本。图表从保存结果生成，并可追溯到图中每条曲线/表项；正式提交前重核哈希和数据→图表链。大文件、训练数据和模型权重先说明存储方案，超过根策略25MB门槛不悄悄加入Git。

旧结果仍在仓库根results，按其manifest、模型和日期使用，不能仅复制旧图标作作业二新实验。
