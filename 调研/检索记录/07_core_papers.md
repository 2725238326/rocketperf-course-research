支持片段：“This report presents the latest... topics include mathematical analyses and techniques for obtaining chemical equilibrium; formulas for obtaining thermodynamic and transport mixture properties... rocket performance based on either a finite- or infinite-chamber-area model”。[[1]](https://ntrs.nasa.gov/citations/19950013764)

**3. DLR LUMEN循环/系统建模论文**  
题名：Validation of the LUMEN EcosimPro Model with Hot-Fire Test Data  
作者：Eldin Kurudzija, Kai Dresia, Vincent Bareiß, Christopher Groll, Max Axel Müller, Tobias Traudt, Michael Börner, Wolfgang Armbruster, Dmitry Suslov, Justin Hardi, Günther Waxenegger-Wilfing, Jan Deeken（DLR Institute of Space Propulsion等）  
年：2025  
DOI：10.13009/EUCASS2025-105  
原始URL：https://www.eucass.eu/doi/EUCASS2025-105.pdf  
实际用途：用EcosimPro/ESPSS建立LUMEN LOX/LNG膨胀循环发动机瞬态系统模型，经部件与整机热试数据验证，用于循环仿真、控制与健康监测开发。  
支持片段：“The LUMEN simulation model is built in EcosimPro with the European Space Propulsion System Simulations (ESPSS) toolkit... the entire LUMEN model is validated using hot-fire test data. The results show that critical parameters... are modelled with high accuracy”。[[3]](https://www.eucass.eu/doi/EUCASS2025-105.pdf)
