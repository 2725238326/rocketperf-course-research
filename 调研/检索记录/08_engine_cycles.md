**1. 天鹊12A/15A循环类型**  
蓝箭航天作者技术论文明确：TQ-12A及其真空变体TQ-15A为80吨级液氧/甲烷发动机家族最新演进，基线TQ-12为燃气发生器循环（gas-generator cycle，即开式循环），12A/15A保持核心架构。[[1]](https://www.sciencedirect.com/science/article/abs/pii/S0094576526003462)

一手来源：Hua Wei等（LandSpace），*Acta Astronautica* Vol.247（2026年10月，DOI 10.1016/j.actaastro.2026.05.033），标题“Tank-head start approach for a 80 ton-class gas-generator cycle methane/LOX rocket engine”。URL：https://www.sciencedirect.com/science/article/abs/pii/S0094576526003462  
短引文：“The TianQue-12A (TQ-12A) and its vacuum variant, TQ-15A, represent the latest evolution of the 80-ton class LOX/methane engine family... The baseline version TQ-12 is a gas-generator cycle engine... These improvements were made while maintaining the core architecture”。关键词含“Gas-generator cycle”。证据范围：作者论文直接描述家族及12A/15A演进，飞行验证至ZQ-3（2025年12月）。中文摘要转载（2026-05-19）一致。蓝箭官网未单独明示循环，此为最直接一手。

**2. YF-100系列富氧补燃及长十乙适用性**  
官方来源确认YF-100（120吨级）采用高压富氧补燃循环（oxidizer-rich staged combustion），130吨级泵后摆发动机充分继承该技术基础。[[2]](https://mp.weixin.qq.com/s/FOiIEhTCDM8nPjT2fWeVuQ)

一手来源1：李斌、刘站国等（航天推进技术研究院/西安航天动力研究所），《载人航天》2022年第4期，中国载人航天官网转载（2023-02-21）。URL：https://www.cmse.gov.cn/dmt/cbw/zrht/2022nian/2022dsiq/202302/t20230221_52733.html  
短引文：“130吨级泵后摆高压补燃液氧煤油发动机...以现役的120吨级高压补燃液氧煤油发动机为基础研制...120吨级发动机采用富氧高压补燃循环方式”。证据范围：130吨泵后摆（YF-100K类，海平面约1250kN）为新一代载人运载火箭（CZ-10系列）一级主动力，已逾万秒试车。

一手来源2：西安航天动力研究所张晓军等，《我国液氧煤油发动机技术发展概述》（中国航天公众号）。URL：https://mp.weixin.qq.com/s/FOiIEhTCDM8nPjT2fWeVuQ  
短引文：“YF-100...发动机采用高压富氧补燃循环方案...130吨级发动机海平面推力1250kN...为新一代载人运载火箭一级主动力装置”。

长十乙（CZ-10B）公开资料将其一级关联YF-100K家族7机并联（高压补燃），但官方（cmse.gov.cn）仅确认CZ-10/甲系列使用该130吨泵后摆，无独立“长十乙首飞子型”循环验证文件。证据限于家族继承与总体设计，不可将系列事实等同具体子型飞行验证。无法核实更细官方链接。
