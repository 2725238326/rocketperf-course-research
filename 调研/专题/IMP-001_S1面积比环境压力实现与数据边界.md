# IMP-001：S1 面积比—环境压力研究切片

证据/实现截止：2026-10-02

## 研究问题

在入口总温、总压、气体常数和喉部面积固定时，面积比与环境压力如何影响 L0 理想准一维喷管的出口状态、推力系数和秒制比冲？哪些点不能由当前模型给出成功结果？

## 数据甄别

本专题没有把公开型号参数直接塞进求解器。`ZQ-3` 和 `CZ-10B` 的公开资料只用于架构背景、构型约束和缺口说明，字段级结论见 [RES-001](RES-001_型号版本与参数缺口.md) 和 `data/parameters/baseline.json`。S1 使用 `cases/research/s1_area_ratio_ambient.ini` 中的显式教学合成输入：`gamma=1.4`、`R=287 J/(kg·K)`、`T0=300 K`、`p0=1 MPa`、`At=0.001 m²`。这些值不是任何真实发动机的实测卡片。

因此当前数据角色是：

| 数据 | 角色 | 可支持的结论 |
|---|---|---|
| 公开型号构型与推进剂标签 | `fact` | 研究背景和参数缺口 |
| 吨力到 N 的单位换算 | `derived` | 量级参考，保留原工况 |
| S1 输入 | `synthetic_benchmark` / `assumption` | 数学趋势、边界和代码回归 |
| S1 输出 | `computed` | 仅对给定模型和输入负责 |

## 实现和校验

- C17 扫描调用与单算例相同的 `rp_nozzle_solve_ideal`，不引入 Python/Fortran 物理核心。
- 点顺序固定为面积比外层、环境压力内层；每个点保留状态和诊断。
- 背压高于理想出口压力的点标记 `out_of_domain`，禁止按零推力或插值成功值使用。
- Mach 2 闭式参考、连续方程、总焓守恒和推力背压差均由现有回归测试覆盖；S1 新增自定义网格和越域点测试。
- 完整工程质量入口 `python tools/quality.py` 在 2026-10-02 通过 project、governance、debug、release、runner 五项检查。

## 不能外推的内容

S1 不能证明真实发动机绝对推力、比冲、喷管分离边界、节流稳定性、冷却裕度、循环功率、结构寿命或重复使用次数。要进入真实型号性能分析，必须先获得字段级室压、面积比、O/F、工况比冲、流量和系统边界证据，并为未知字段建立带范围和理由的独立假设记录。
