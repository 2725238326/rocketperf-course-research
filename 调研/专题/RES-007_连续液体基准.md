# RES-007：连续单相 CH₄/O₂ 参考和化学焓对齐

证据截止：2026-10-05。问题是“能否用一份可复验的离线表替代固定液态锚点，给后续 C17 连续温压查询提供密度和同化学零点的焓”。

## 结果

已生成[固定参考](../../results/research/liquid_feed_reference_v1/manifest.json)：407 个温压网格点、700 个单元内部参考、107 个饱和液/汽状态对、14 个理想项温度点和24个成功/拒绝查询。两个矩形均在单相液体侧，满足预先设定的临界与饱和裕量；输入全部是研究假设。

| 研究状态，P=10 MPa | EOS 质量密度 | 对齐摩尔焓 | 按 CEA 分子量换算的质量焓 |
|---|---:|---:|---:|
| CH₄，120 K | 419.793800 kg/m³ | −88521.901918 J/mol | −5517975.542266 J/kg |
| O₂，100 K | 1116.286536 kg/m³ | −12252.605872 J/mol | −382908.292572 J/kg |

这些数来自 CoolProp 7.1.0 HEOS，经本项目独立系数计算复核。它们没有匹配任何真实发动机入口，也没有求泵或燃烧；后续 C17 查表接口按[契约](../../docs/liquid-feed-contract.md)实现。

## 固定身份与原文

沿用 RES-006 已保存的官方原文：`F02` 甲烷 JSON、`F03` 氧气 JSON、`F04` MIT LICENSE、`F07` BibTeX；文件和 URL 的固定哈希位于运行清单 `source_files`。甲烷 EOS 引用为 Setzmann-JPCRD-1991，氧气为 Schmidt-FPE-1985；系数和参考偏置都从固定 JSON 读取。NASA9 使用既有 CEA v3.3.4 / commit `4c5c612efa2002a94e3a5a1f33b1674d55c65340` 原文。

参考软件固定为 CoolProp 7.1.0 / gitrevision `2a1c5d7231011ed1c20067b8528150398d12c841`，Windows CPython 3.13 x64 wheel，SHA256 `9846aabfcc7c72d8fb8f1bd02f6c58125640b6e8e4321487c4746ede7a4590da`；PyPI 版本元数据返回的 wheel 哈希与下载字节一致。扩展二进制哈希、Python 版本/可执行文件哈希、架构、平台、原始输入/输出和 stderr 均已保存。

导出流体 JSON 和 Git 原文存在二进制浮点序列化末位差异，复核只容许数值相对误差 `5e-15`，对象/字段/非数值项仍须一致；不是忽略不同系数。初次生成因误用了不存在的 `gmolar()` 接口失败，完整失败清单和 stderr 留在 `build/liquid-feed/363257196bb54f0c838b55ec80d4a59f/`；改用该版本真实的 `gibbsmolar()` 后生成成功。

未新增型号检索或新型号事实，研究不因本地日期自动刷新型号资料截止。

## 为什么不能只调一个零点就宣布一致

按 `H_aligned = H_HEOS − H_HEOS,ideal(298.15) + H_NASA9,ideal(298.15)` 对齐，保留全部残余焓。甲烷的质量口径相差约 21.19 ppm；氧气两库气体常数相差 0.00017 J/(mol·K)。这些差异均显式保存。

| 200–600 K 七个理想气体采样 | CH₄ | O₂ |
|---|---:|---:|
| 最大 \|cp_HEOS − cp_NASA9\| | 0.198839 J/(mol·K) | 0.008060 J/(mol·K) |
| 对齐后最大理想焓差 | 16.810986 J/mol | 1.014824 J/mol |
| 错用298.15 K、100 kPa真实气体h作锚点时引入的残余项 | −15.660996 J/mol | −7.902321 J/mol |

甲烷最大焓差出现在600 K；氧气出现在500 K。它们不是液体插值误差，也不因零点已对齐而消失。这里建立的是明确的组合参考，不强改 HEOS 比热去拟合 NASA9；NASA9 没有被外推到100/80 K。

## 独立核验到哪一步

`tools/liquid_eos.py`从固定 EOS 的幂函数/Gaussian 残余项和理想项解析计算，分别复核所有温压点的 p、h₀、hᵣ、h、cp₀ 及正压缩稳定性导数。液体密度必须高于同温饱和液体密度；饱和液/汽两根复算 p 与 Gibbs 相等，液体密度大于汽体、汽体焓大于液体。100 kPa 理想项检查另用独立气体密度夹逼求根，避免共同改动 h/hᵣ仍通过差值检查。

107 对饱和点包括所有网格和内部样本温度。最低 P/Psat 为甲烷1.559621、氧气1.840265。高层/低层 API 检查是同库交叉检查；解析复算是同系数独立实现。两者都不是实验物性或真实发动机验证。

双线性插值在700个内部样本上的误差满足预设门槛：密度≤0.05%、焓≤5 J/mol；实际最大为0.010135%和0.459415 J/mol。中心和¼/¾点共同采样仍不能声称连续域误差上界，契约保留这项限制。

## 可接续的产物

`raw-output.json`保存软件原输出及导出原文；`tables.json`保存密度、摩尔/质量焓和误差；离线verify不安装 CoolProp 也能运行。测试覆盖22种语义篡改，其中包括重新计算文件哈希后的密度、残余焓、饱和压力、错相、比热、共模焓改动、零点、质量口径和重复JSON键。

研究证据已经足以实现一个受限 C17 查表接口；当前真实型号入口温压、批次、纯度仍未知，煤油仍需独立路径。查表将先作为物性功能落地，再评估对HP和循环的作用，不能连带宣布泵或完整循环已经闭合。
