# RES-003：课程公式与基准算例

## 研究问题

把课程课件中真正会影响本作业的量、单位和边界整理成可检查的公式表，并确认哪些结果已有独立参考，哪些只是待实现或未复现的候选算例。页码按本地课件《第2章推力室和发动机的主要参数20260911.pptx》的页序；课程范围冲突和作业安排见 `调研/课程范围与资料冲突.md` 与 `作业要求/大作业1_要求存档.md`。

## 当前可直接采用的公式

### 推力、总冲和比冲（课件 P9、P11–P12）

| 量 | 定义 | 单位/边界 | 本项目处理 |
|---|---|---|---|
| 推力 `F` | `F = mdot * ve + (pe - pa) * Ae` | N；必须统一出口、环境和流量控制体 | 当前C基线已实现；主室/整机要分开命名 |
| 总冲 `It` | `It = ∫F dt` | N·s；需要给出时间历程或分段情景 | 无真实飞行时间历程时只做研究情景 |
| 秒制比冲 `Isp_s` | `Isp_s = F / (mdot * g0)` | s，`g0=9.80665 m/s²` | 与速度量纲的等效喷气速度不能混写 |
| 等效喷气速度 `c_eff` | `c_eff = F / mdot = g0 * Isp_s` | m/s | 课件 P11–P12 的速度口径单独保留 |

课件同时强调静态/动态、海平面/真空和设计状态不能混比。主室流量 `mdot_chamber` 与发动机总消耗 `mdot_engine` 不是默认相等，支路排气若产生推力必须进入同一推力控制体。

### 理想推力室与准一维喷管（课件 P13–P19；项目基准 `docs/benchmarks.md`）

在定比热、绝热、稳态、无黏、等熵和一维平均流假设下：

```text
Ae/At = (1/Me) * [2/(gamma+1) * (1+(gamma-1)*Me^2/2)]^((gamma+1)/(2*(gamma-1)))
Te/T0 = 1 / (1+(gamma-1)*Me^2/2)
pe/p0 = (Te/T0)^(gamma/(gamma-1))
ve = Me * sqrt(gamma * R * Te)
c* = sqrt(R*T0/gamma) * [(gamma+1)/2]^((gamma+1)/(2*(gamma-1)))
mdot = p0*At/c*
F = mdot*ve + (pe-pa)*Ae
CF = F/(p0*At)
Isp_s = F/(mdot*g0)
```

符号：`p0/T0`为燃烧室或储室总压/总温，`pe/Te`为出口静态压/温，`pa`为环境背压，`At/Ae`为喉部/出口面积，`Me`为出口马赫数，`gamma`为比热比，`R`为比气体常数，`mdot`为通过喉部的质量流量。该组公式是教学基线，不含化学反应、温变物性、黏性/热损失、激波、分离、冷却和循环支路。

课件 P19 的参数关系图用于检查依赖和量纲，不作为独立准确性证据；由同一恒等式反推输入不能算作独立验证。

### 实际性能分层（课件 P23–P24）

课件把实际特征速度、实际推力系数、燃烧室效率、喷管效率和比冲效率分开。报告中应至少保留：

```text
c*_actual = eta_cstar * c*_ideal
CF_actual = eta_nozzle * CF_ideal       (仅在明确采用该分解时)
Isp_actual = F_actual / (mdot_engine*g0)
```

这些效率不是目标型号的默认常数。没有台架或文献依据时，只能做显式情景，不能借效率系数伪造实测发动机结果。

## 独立基准算例 C0

`docs/benchmarks.md` 和 `cases/mach2.ini` 定义人为构造的定比热理想空气算例：

| 输入 | 值 | 角色 |
|---|---:|---|
| `gamma` | 1.4 | 教学假设 |
| `R` | 287 J/(kg·K) | 空气近似的教学假设 |
| `T0` | 300 K | 教学输入 |
| `p0` | 1,000,000 Pa | 教学输入 |
| `At` | 0.001 m² | 流量/推力尺度假设 |
| `Ae/At` | 27/16 = 1.6875 | 由 `Me=2`解析构造 |
| `pa` | 0 Pa | 真空教学边界 |

通过先指定 `Me=2` 再构造面积比，出口马赫数参考值不依赖待测二分求根。独立闭式计算得到：`Te=166.66666666666667 K`、`pe=127804.52546295094 Pa`、`ve=517.5583702991061 m/s`、`c*=428.53006428954317 m/s`、`mdot=2.3335585606062264 kg/s`、`F=1423.4229023436161 N`、`CF=1.4234229023436161`、`Isp=62.200599374151 s`。参考文件为 `tests/reference/air_mach2.json`；这是代码/公式验证，不是实验或真实火箭验证。

补充关系：`gamma=7/5, Me=3` 时 `Ae/At=343/81`；`gamma=5/3, Me=2` 时 `Ae/At=49/32`；`Ae/At=1` 的超声速求解边界退化为声速喉部。相同几何和储室条件下，背压从0变为100000 Pa时，理想推力减少 `pa*Ae=168.75 N`；喉部面积加倍时，推力和流量加倍而 `CF/Isp`不变。

## 公式与模型边界

- `gamma`、`R` 固定时只能回答理想气体参数变化，不能回答推进剂混合比最优、燃烧温度或真实比冲。
- 课件 P25 的发动机比较表用于说明循环、真空推力、室压、混合比、面积比和质量的字段结构；其中示例型号数字不能直接作为朱雀三号或长征十号乙输入。
- 推进剂/循环、室压、面积比和流量若来自不同批次或不同控制体，不能拼成一个“真实型号算例”。公开缺口见 `RES-001_型号版本与参数缺口.md`。
- C0 基准的每个输入必须带 `synthetic_benchmark` 角色；目标型号只能进入 `research_scenario`，且未公开字段必须有假设编号。
