<h1>C<a class="headerlink" href="#c" title="Link to this heading">¶</a></h1>
<p>Notes:</p>
<ul class="simple">
<li><p><code class="docutils literal notranslate"><span class="pre">cea_mixture_get_species_name</span></code> and <code class="docutils literal notranslate"><span class="pre">cea_mixture_get_species_names</span></code> return heap-allocated strings and are deprecated.
Use <code class="docutils literal notranslate"><span class="pre">cea_mixture_get_species_name_buf</span></code> / <code class="docutils literal notranslate"><span class="pre">cea_mixture_get_species_names_buf</span></code> instead. If you use the deprecated APIs,
free results with <code class="docutils literal notranslate"><span class="pre">cea_string_free</span></code> or <code class="docutils literal notranslate"><span class="pre">cea_string_array_free</span></code>.</p></li>
<li><p>Input string arrays passed into the API (species, reactants, omit, insert) are copied by the C/Fortran layer during
the call. Callers retain ownership and may free or reuse their buffers after the call returns.</p></li>
<li><p><code class="docutils literal notranslate"><span class="pre">cea_rocket_solver_get_eqsolver</span></code> is no longer exposed; use <code class="docutils literal notranslate"><span class="pre">cea_rocket_solver_get_size</span></code> and other RocketSolver APIs.</p></li>
<li><p>Rocket, shock, and detonation solution property getters now require a <code class="docutils literal notranslate"><span class="pre">len</span></code> argument and will return
<code class="docutils literal notranslate"><span class="pre">CEA_INVALID_SIZE</span></code> if <code class="docutils literal notranslate"><span class="pre">len</span></code> is smaller than the internal number of points.</p></li>
<li><p><code class="docutils literal notranslate"><span class="pre">cea_shock_solver_solve</span></code> may return <code class="docutils literal notranslate"><span class="pre">CEA_LAST_VALID_SOLUTION</span></code> when the incident-equilibrium solver retains
a last valid state for inspection without converging the shock iteration. In that case the returned properties
remain readable, but <code class="docutils literal notranslate"><span class="pre">cea_shock_solution_get_converged</span></code> still reports false.</p></li>
</ul>

<p>The C-API used the Fortran bind-c interface to call Fortran routines from C. This provides a way to use Fortran libraries in C programs, as well as an interface for other languages that can call C functions, including Python.</p>
</section>
