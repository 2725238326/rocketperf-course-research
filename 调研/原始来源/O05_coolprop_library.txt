  <section id="shared-library-dll">
<span id="shared-library"></span><h1>Shared Library (DLL)<a class="headerlink" href="#shared-library-dll" title="Link to this heading">#</a></h1>
<section id="general-information">
<h2>General Information<a class="headerlink" href="#general-information" title="Link to this heading">#</a></h2>
<p>Shared libraries are compiled code that can be accessed by other programs.  On windows, they are DLL files, on other platforms .os (linux) or .dylib (OSX)</p>
<p>There are a few things that need to be considered when determining what shared library you should build/use:</p>
<ul class="simple">
<li><p><a class="reference external" href="https://en.wikipedia.org/wiki/Calling_convention">Calling convention</a>: <code class="docutils literal notranslate"><span class="pre">__stdcall</span></code> or <code class="docutils literal notranslate"><span class="pre">__cdecl</span></code> - only a consideration on 32-bit windows</p></li>
<li><p>Architecture: 32-bit or 64-bit</p></li>
<li><p>Compiler: Visual Studio, Mingw, GCC, clang</p></li>
</ul>
</section>
<section id="pre-compiled-binaries">
<h2>Pre-Compiled Binaries<a class="headerlink" href="#pre-compiled-binaries" title="Link to this heading">#</a></h2>
<p>Download the appropriate shared library for your architecture from <a class="extlink-sfdownloads reference external" href="https://sourceforge.net/projects/coolprop/files/CoolProp/8.0.0/shared_library">8.0.0 shared_library</a>, or the nightly development versions at <a class="extlink-sfnightly reference external" href="https://sourceforge.net/projects/coolprop/files/CoolProp/nightly/shared_library">nightly shared_library</a>.</p>
<p>Users of the Borland compiler might find these instructions useful for using Visual Studio compiled shared libraries with Borland compiler: <a class="reference external" href="https://bcbjournal.org/articles/vol4/0012/Using_Visual_C_DLLs_with_CBuilder.htm">https://bcbjournal.org/articles/vol4/0012/Using_Visual_C_DLLs_with_CBuilder.htm</a></p>
</section>
<section id="user-compiled-binaries">
<h2>User-Compiled Binaries<a class="headerlink" href="#user-compiled-binaries" title="Link to this heading">#</a></h2>
<section id="common-requirements">
<h3>Common Requirements<a class="headerlink" href="#common-requirements" title="Link to this heading">#</a></h3>
<p>Compilation of a shared library requires a few <a class="reference internal" href="../index.html#wrapper-common-prereqs"><span class="std std-ref">common wrapper pre-requisites</span></a></p>
</section>
<section id="windows">
<h3>Windows<a class="headerlink" href="#windows" title="Link to this heading">#</a></h3>
<p>On windows, the greatest amount of complexity is experienced.</p>
<p>Your compiler options are:</p>
<ul class="simple">
<li><p><a class="reference external" href="https://www.msys2.org/">MSYS2</a> UCRT64 (formerly MinGW, a windows port of GCC)</p></li>
<li><p>Visual Studio, multiple versions can be installed in parallel</p></li>
</ul>
<p>By default, cmake will use your most up to date version of MS Visual Studio it finds.</p>
<div class="admonition warning">
<p class="admonition-title">Warning</p>
<p>The old MinGW GCC may have problems building the latest version of CoolProp.  Use a more recent toolchain (for instance via <a class="reference external" href="https://www.msys2.org/">MSYS2</a>) that ships a modern GCC.</p>
</div>
<p>Your calling convention options are:</p>
<ul class="simple">

<p>Based on the discussion on <a class="reference external" href="https://github.com/CoolProp/CoolProp/issues/1600">GitHub</a>, you can use the following steps to link against the CoolProp libraries:</p>
<div class="highlight-default notranslate"><div class="highlight"><pre><span></span>cat &lt;&lt;EOF &gt; main.cpp
#include &lt;iostream&gt;
#include &quot;CoolProp/CoolPropLib.h&quot;
int main(){
    double T{293.15};
    double P{1e5};
    //double res{0.0};
    double res{PropsSI(&quot;D&quot;, &quot;T&quot;, T, &quot;P&quot;, P, &quot;Water&quot;)};
    std::cout &lt;&lt; &quot;Density: &quot; &lt;&lt; res &lt;&lt; std::endl;
}

EOF
g++ -std=c++11 -Wall -O2 -o main -DCOOLPROP_LIB -I../include main.cpp libCoolProp.so -ldl
LD_LIBRARY_PATH=`pwd` ./main
