# 最终讲稿（双人，13页正文）

A讲P1–P7，B讲P8–P13，P7末交接一次。展示15分钟、提问另计5分钟；计划13:55，留65秒机动，含三次演示共100秒。每页标题、文字和数字与[逐页指南](ppt-structure.md)一致。

## 全场主线

老师布置了三件事：**调查两型火箭的动力方案，用所学理论算出性能参数，研究优缺点和改进**，核心程序用C。整场按这三件事推进：

| 老师要求 | 我们的回答 | 页 |
|---|---|---|
| 调查动力方案 | 四个级段，四种工作环境 | P2 |
| 计算性能参数 | 自己写的C程序，从推进剂入口算到整台发动机 | P3–P5 |
| 研究优缺点和改进 | 燃烧、推进剂、喷管、循环四个取舍，每个都有数 | P6–P10 |
| 落回两型火箭 | 四个级段各得到一条判断 | P11 |
| 结果可信 | 三层核对，能现场复算 | P12 |

写法约定：每页第一句接回主线，最后一句引出下一页。括号是动作，不念。**加粗句**必须讲到，其余可用自己的话。

## P1 封面　A　20秒

**屏幕**：两型运载火箭动力系统性能研究。

各位老师同学好。我们组研究朱雀三号和长征十号乙的动力系统。老师的要求是三件事：调查方案、计算性能、研究改进。我们的做法是**自己用C写一套计算程序，让每个改进判断都有数字支撑**。先看两型火箭有什么不同。

## P2 四个级段，四种工作环境　A　60秒

**屏幕**：四个菱形图标，每个级段一行事实、一行关注点。

（先指左边两个一级，再指右边两个二级。）

第一件事是调查方案。两型火箭拆开是四个级段。朱雀三号一级是九台液氧甲烷TQ-12A，二级是一台真空型TQ-15A，要能二次点火。长征十号乙一级是七台百吨级液氧煤油发动机，二级是140吨级液氧甲烷动力。

**一级在海平面大气里起飞，二级在接近真空的高空工作，还要再点火。** 环境不同，“哪台发动机好”就没有统一答案，要分级段算。公开资料没有给室压、喉部面积，我们把它们设成明确的研究输入，换一组输入就能重算。

那我们做出了什么？

## P3 我们交出了什么　A　55秒

**屏幕**：4个级段、6627行、2种循环、13722项。

（从左到右依次指四个数字。）

四样东西。四个级段的方案和参数，逐项核对了来源；六千六百多行C代码，从推进剂入口算到喷管出口；开式和富氧补燃两种循环，整台发动机的流量和功率都能算平；一万三千多项检查，全部通过。

**这套程序不只给出数字，还能说明数字为什么变。** 第二件事是计算，先看怎么算。

## P4 从推进剂入口算到整台发动机　A　60秒

**屏幕**：四层台阶，右侧三个公式。

（台阶从上往下指，最后指公式。）

课本上的理论，我们拆成四步。第一步，由推进剂进来时的温度和压力，算出它带进多少能量、多少碳氢氧；第二步，在给定室压下燃烧到化学平衡，得到燃气温度和成分；第三步，燃气流过喷管，得到流量、推力和比冲；第四步，把泵和涡轮放进来，算整台发动机。

右边三个公式后面会反复用到。**比冲等于CF乘c\*：c\*看燃烧，CF看喷管。** 后面每个结果，我们都先问一句：变的是c\*，还是CF？

这四步写成了一个什么样的程序？

## P5 自己写的C程序：6627行，六个模块　A　60秒

**屏幕**：六个模块条带及行数，下方横栏三项。

（沿条带从左指到右，再指横栏。）

老师要求核心用C，这就是我们的程序。从左到右是数据走的路：输入模块检查参数，缺一项、多一项、拼错一项都会被挡住；热化学模块算燃烧平衡；喷管模块算出口；循环模块算整机；命令行和菜单让人直接使用；最底层统一处理错误。

怎么保证算得对？编译时出现一个警告就不让通过；一万三千多项检查每次修改都重跑；燃烧平衡的求解我们重写过，迭代从约30次降到8次，快了6倍多。**算不了的工况，程序直接拒算，不会给出一个看起来正常的错数。** 下一页就会看到。

## P6 燃烧不是越热越好　A　80秒（含25秒演示）

**屏幕**：c\*–O/F曲线，标c\*峰和温度峰；左下拒算小框。

（指曲线顶点，再指右侧虚线。B准备演示页1。）

第三件事是研究改进，先从燃烧室开始：氧和燃料按什么比例混合最好？直觉是越热越好。但这条曲线上，**c\*在O/F 2.7最高，温度却要到3.7才最高。** 氧加多了，燃气是更热，可是生成的水和二氧化碳更多，燃气变重，同样的温度推不出同样的速度。后面我们取2.6，离c\*最高点只差0.13%。

（B切演示页1，点“发生器1.0”，再点“凝聚碳区”。）往燃料多的一边走，又是另一个问题：积碳。O/F降到0.8时，程序判断固体碳已经能稳定存在，我们的气体模型不再适用，于是直接拒算。这就是上一页说的“算不了就不给数”。

（回PPT。）比例定了，换一种推进剂会怎样？

## P7 比冲高14秒，推力为什么不变？　A　90秒（含25秒演示、10秒交接）

**屏幕**：三行对比条：比冲、流量、推力。

（先指比冲行，停一下，再指流量和推力行。）

两型火箭的一级，正好一个烧甲烷、一个烧煤油。我们用同一台“虚拟发动机”比较：室压、喉部、喷管、环境全都一样。甲烷比冲324秒，煤油311秒，高了将近14秒。推力呢？只差0.2%，几乎一样。

（B切演示页2，点“报告口径2.6/2.6”。）答案在流量这一行：同样的喉部，甲烷每秒少流过2.5公斤推进剂。**推力一样，甲烷用得更少，这就是比冲高的含义。** 用公式说：c\*变了，CF几乎没变。

（回PPT。）燃烧和推进剂讲到这里，下面请我的同学接着讲喷管和整机。

**B接话**：我接着用这台甲烷发动机，只改喷管。

## P8 喷管越大越好吗？　B　70秒

**屏幕**：Isp–ε曲线，标ε=10、20、40；三个胶囊131、51、39%。

（指曲线10到20段，再指20到40段，最后指胶囊。A准备演示页4。）

喷管出口越大，燃气膨胀越充分。面积比从10加到20，比冲多13秒，出口面积多0.1平方米；再从20加到40，比冲只多10秒，面积却要多0.2平方米。

按每平方米出口面积换来的比冲算，前一段是131秒，后一段只剩51秒。**第二次加大，回报只有第一次的四成。** 喷管越大越重、越难冷却，这条曲线说明了从哪里开始不划算。这还只是真空里的账，一级要面对大气。

## P9 同一个喷管，换个高度就不一样　B　80秒

**屏幕**：四象限，左右是面积比10/40，上下是真空/海平面，右下黑格打叉。

（先指左列上下两格，再指上排右格，最后指右下黑格。不切网页。）

这一页回答P2提出的一级和二级的区别。先看左列：同一个喷管，从真空搬到海平面，比冲从324秒降到305秒，**大气压一下子吃掉19秒。**

上排是二级的处境：在真空里把喷管放大到40，又多拿23秒。一级能不能也用这么大的喷管？看右下角：在海平面，燃气出口压力只有17千帕，外面大气是101千帕，燃气被外界往回压，程序判断超出了模型的适用范围，拒算。真实喷管在这种情况下容易发生流动分离。

所以二级用大喷管、一级用短喷管这条工程经验，我们用计算找到了它的边界。喷管之外，发动机还得自己带动泵。

## P10 涡轮燃气去哪里：开式与补燃　B　90秒（含50秒演示）

**屏幕**：左环“朱雀三号一级·开式”，右环“长十乙一级·富氧补燃”，中间“整机收支同时算平”。

（A切演示页4，选“开式”，点涡轮。）

泵靠涡轮带动。涡轮的燃气从哪来、到哪去，就是两种循环的区别。左边是按朱雀三号一级设的开式情景：一小股推进剂在燃气发生器里烧掉，推动涡轮后直接排出，每秒约1.9公斤，占总量2%，主喷管拿到98公斤。涡轮出口压力是我们给定的0.8兆帕。

（A切“补燃”，再点涡轮。）右边是按长十乙一级设的富氧补燃情景：涡轮排出的燃气不扔，全部送回主燃烧室，主喷管拿到完整的100公斤。代价是涡轮出口必须保持高压，才能把燃气送回去。这个压力不是我们给的，是程序让泵和涡轮功率相等，反推出来的，约18兆帕。

（回PPT，指中间大圆。）**进来多少、出去多少，泵要多少功、涡轮给多少功，程序都把账算平了。** 两边本来就是两型火箭，推进剂不同，这里不比谁好，比的是两种循环各自怎么算平。

## P11 回到四个级段　B　65秒

**屏幕**：四个圆形图标，每个级段一条判断、一行约束。

（逐个指图标，蓝色小字不念。）

现在回到P2的四个级段，每个给一条有计算依据的判断。朱雀三号一级：海平面上喷管不能贪大，边界就是P9的拒算点。朱雀三号二级：真空工作可以放大喷管，但P8说明回报在递减。长十乙一级：补燃要让泵压、涡轮和回流压力同时满足，P10就是这样算的。长十乙二级：同样是甲烷动力，P6、P7的甲烷结果可以直接作为起点。

**每条建议都带着收益、代价和适用条件**，而不是一句“提高室压”或“加大喷管”。这些数字靠得住吗？

## P12 这些数字靠得住吗？　B　55秒

**屏幕**：01守恒、02对照CEA、03现场复算。

（依次指01、02、03。）

我们从三个方向核对。第一，守恒：质量、元素、功、能量，每一项都检查是否算平。第二，对照：和美国宇航局的CEA软件比，39个算例、2148个数，全部在误差范围内。第三，复算：程序可以直接运行，演示页上每个结果都附有运行命令。**老师给一组新参数，我们现场就能算。**

最后回到老师的三件事。

## P13 回到老师的三件事　B　50秒

**屏幕**：波浪四段：燃烧、推进剂、喷管、循环。

（沿波浪从左指到右。）

调查方案，我们把两型火箭拆成四个级段，看清了各自的工作环境；计算性能，我们写了一套C程序，从推进剂入口算到整台发动机；研究改进，我们得到四个结论：**燃烧不是越热越好，比冲高是因为用得省，喷管要看在什么高度工作，循环要把整机的账算平。**

下一步，把真实发动机的参数填进去，再加上冷却和结构，就能把这些判断变成具体的设计数字。我们的汇报到这里，谢谢，欢迎提问。

（翻到致谢页，停住。）

## 5分钟问答

讲哪半场的人先答，另一人补充。先说结论，再说条件，每题30–45秒。没有的数据就说“这个参数公开资料没有，我们用的是研究输入”，不现场编数。

| 可能问题 | 短答 |
|---|---|
| 你们最大的特点是什么？ | 每个改进判断都有同条件的计算支撑，程序能现场换参数复算。 |
| 代码是你们自己写的吗？ | 是。C17手写约6600行，六个模块；可以现场打开源码或运行菜单。 |
| 为什么要那么严格的编译和检查？ | 数值程序最怕悄悄算错，比如类型转换丢精度。警告当错误、每次修改都跑全部检查，这类错误在出结果前就被拦下。 |
| O/F 2.7就是最佳设计吗？ | 它是c\*最高的点。实际选型还要看推进剂密度、贮箱大小和冷却，所以真实发动机未必取这个值。 |
| 甲烷比冲高，为什么推力不变？ | 喉部和室压固定时，推力由喷管系数CF决定，两种推进剂CF几乎一样；变的是流量，甲烷用得更少。 |
| 为什么温度最高不是c\*最高？ | c\*取决于温度和燃气平均分子量之比。氧多时温度还在升，但水和二氧化碳增多，燃气变重得更快。 |
| 碳判据能预测积碳吗？ | 它判断固体碳会不会出现，用来划定模型的使用边界，不预测积碳多快、积在哪里。 |
| 拒算是不是说明已经分离？ | 说明进入了容易分离的区域，超出附着流动模型的范围。分离发生在哪需要更细的模型。 |
| 补燃一定比开式好吗？ | 我们两个情景对应两型火箭，推进剂和参数都不同，不能直接排名。补燃不浪费推进剂，代价是涡轮压力和泵压要求更高。 |
| 涡轮出口压力是你们定的吗？ | 开式的0.8兆帕是输入；补燃的约18兆帕是程序按泵和涡轮功率平衡反算的，迭代27次。 |
| 喉部为什么取马赫数1？ | 稳态工作的火箭喷管喉部是声速，我们按这个前提求解。 |
| 平衡计算有几个未知数？ | 碳、氢、氧三个元素势加总摩尔数，共4个。 |
| 实际推力比计算低多少？ | 取决于摩擦、分离和燃烧效率，没有统一折扣，要靠试验或更细的模型确定。 |
| 多台发动机推力能直接相加吗？ | 先按摆角投影到箭体轴线，再相加。 |
| 和CEA对上就说明准确吗？ | 说明程序实现正确。真实发动机的性能还要用试验数据标定。 |
| 6倍提速是怎么来的？ | 原来每次平衡都从6000 K重新算，改成用上一次的结果作起点，并换了更快的求根方法；310个算例实测，结果差约百万分之一开尔文。 |
