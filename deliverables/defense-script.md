## P1 A：开场（20秒）

各位老师同学好。我们研究朱雀三号和长征十号乙的动力系统。这次工作一方面梳理两型火箭的动力方案，另一方面把课程理论实现为C语言程序，用计算解释燃烧、推进剂、喷管和循环的设计取舍。先看两个型号的四个级段。

## P2 A：两型方案与工作能力（70秒）

（先指一级，再指二级，不从左到右逐格读。）

朱雀三号遥一一级采用九台TQ-12A液氧甲烷发动机，二级采用一台TQ-15A真空型并具备二次起动能力。长征十号乙首飞一级采用七台百吨级液氧煤油动力，其中五台可摇摆和二次起动，两台固定；二级公开描述为140吨级液氧甲烷动力。

这里最值得比较的是任务差别：一级要面对起飞背压和回收相关约束，二级更关注低背压性能和再起动。因此，我们不能只拿一个比冲数字评价整个动力系统。公开资料还缺少同批单机室压、喉面积等完整输入，我们把这些作为明确的研究假设，分别讨论不同设计因素的影响。

## P3 A：成果与关键工作（70秒）

（依次指四列，每列只说一个动词和一个结果。）

第一，我们按四个级段整理了动力方案、工作能力和参数依据。第二，我们把液体入口焓、九气相平衡和冻结喷管做成C17计算程序，支持液甲烷和指定RP-1方法。第三，我们把计算扩展到开式和富氧补燃循环，并研究喷管几何、背压和支路的收益代价。第四，程序可以直接运行，输入、输出与失败原因都有记录，结果能复算。

我们希望突出的是：不仅给出结果，还能解释结果为什么变化。液体焓和变比热让计算更具体，同条件比较让原因更清楚，守恒检查和越域拒算让输出更容易核对。下面用一页说明这套计算如何组织。

## P4 A：计算方法（60秒）

（指左右两条路径，然后只指三个公式。）

推力室路径先由入口状态得到焓和元素库存，给定压力求定焓定压平衡，得到温度与组成，再用室内组成冻结的喷管求流量、推力和比冲。循环路径还要加入泵压、效率、支路和回流条件，把预燃室、涡轮与主室联合计算。

后面请记住三个关系：流量等于Pc乘At再除以c*，推力等于CF乘Pc和At，比冲等于CF乘c*再除以g₀。这样我们就能分清一种变化主要影响的是燃烧性能、流量，还是推力系数。先看燃烧室。

## P5 A：燃烧峰值与碳判据（80秒，含25秒演示）

（指c*曲线的峰值；B准备演示页1。）

固定液甲烷120K、液氧100K和10MPa室压，当前采样中c*在O/F约2.7达到1845.24米每秒，温度峰却在3.7。这说明温度最高不等于c*最高，平均摩尔质量和比热比也共同影响结果。后续取2.6，距这个采样c*峰约0.13%。

富燃端还需要检查模型是否适用。（B点“发生器1.0”，再点“凝聚碳区”。）O/F为1.0时，石墨活度约0.883；降到0.8时约1.32，大于1意味着凝聚碳更稳定，程序拒绝继续把九气相结果当作有效性能。这个判据不预测积碳速率，但能识别模型遗漏稳定凝聚相的情况。

燃烧室状态不同，放进同样的几何里又会怎样？

## P6 A：推进剂比较与交接（90秒，含25秒演示及10秒交接）

（先指Isp行，停一下，再指流量与推力行。B切演示页2，恢复“报告口径2.6/2.6”。）

固定同样的室压、喉面积、面积比10和真空，两种方法都取O/F为2.6。液甲烷比冲324.43秒，RP-1方法310.57秒，相差13.85秒。但推力只差约0.20%，并没有同比例增加。为什么？

因为固定PcAt后，流量主要通过c*变化，这里甲烷流量少约4.46%；推力则由CF决定，所以要把两者分开解释。这就是同条件比较的价值，不能只报一个比冲。两种方法仍保留各自入口状态，同O/F不等于同当量比，RP-1也不等于国产煤油批次。

（回PPT。）推进剂的取舍先讲到这里，下面请第二位同学沿用同一组输入，继续看喷管和整机循环。

**B接话：**我先固定液甲烷O/F为2.6，只改变喷管几何。

## P7 B：喷管收益与代价（70秒）

（指曲线10到20，再指20到40，A准备后续操作。）

面积比从10增到20，真空比冲增加13.12秒，出口面积增加0.10平方米；再从20增到40，比冲增加10.20秒，但面积增加0.20平方米。两段换算成单位面积收益，分别约131.18和50.99秒每平方米，后一段只有前一段的39%。

所以扩大喷管确实能提高真空性能，但边际收益在下降。工程上还要把它和长度、质量、冷却等约束一起评价。当前计算给出了几何收益，尚未给出真实最优尺寸。而一级还有大气背压，接着看这一点。

## P8 B：背压与喷管适用域（80秒）

（先指同ε10的两行数字，再指ε40示意。保持静态，不切网页。）

先保持面积比10不变。同一喷管在真空的比冲是324.425秒，在海平面是305.384秒，背压使比冲下降约19.04秒。这是同一几何的环境变化。

如果改成面积比40，理想出口压力约17.24千帕，低于海平面背压101.325千帕，当前附着流动模型拒算。这是在提示适用域，尚未预测真实分离位置。真空中面积比40相对10的23.32秒增益属于另一种比较，不能混成真空和海平面之差。

因此，喷管改进必须和工作环境一起讨论；低但非零背压下也可能有扩大喷管的收益。除了喷管，整机还要为推进剂泵提供功率。

## P9 B：开式、补燃与整机收支（90秒，含50秒演示）

（A切网页4，先开式，点涡轮。）

开式研究情景中，约1.93千克每秒通过发生器支路外排，主流量约98.07千克每秒。外排支路仍有轴向推力，所以不能从整机推力账里漏掉。这里涡轮出口压力0.8MPa是给定输入。

（A切补燃，仍点涡轮。）富氧补燃情景中，支路回流主室，主喷管流量仍为100千克每秒。程序在满足返回压力约束的条件下，通过轴功平衡反解涡轮出口压力，得到约17.95MPa。

这页展示的成果，是把外排或回流、泵功和主室状态放进同一套收支里核对。两列的燃料、混合比和泵压不同，不能只据比冲排名。残差也按各自单位解释，只有轴功和焓流残差用瓦。

回到四个级段，这些计算能支持哪些判断？

## P10 B：有计算依据的改进判断（75秒）

（按一级/二级两组讲，不重复整张表。）

对于朱雀三号一级，我们更关注海平面喷管域和发生器外排代价；二级则可以利用低背压下的喷管收益，同时评估扩张后的质量和冷却。对于长十乙一级，富氧支路、泵压、轴功和返回压力需要一起满足；二级已有甲烷动力的公开描述，循环子型还需同批证据，因此保留分支情景。

我们的改进思路是先在同条件下算收益，再把几何代价和适用条件放回来。这比只说“提高室压”或“扩大喷管”更具体。要进一步量化实机改进量，还要补同批参数、部件效率和冷却约束。接下来说明这些结果经过了哪些核对。

## P11 B：核验与程序使用（70秒）

（指三列，不逐项报所有测试数量。）

第一层是守恒和趋势核对，质量、元素、轴功和焓流分别检查，接受与拒算工况都有记录。第二层是参考软件对照，甲烷和RP-1合计39张CEA卡、2148个字段，没有字段超过各自容差。第三层是可复算的使用流程，核心直接由C运行，支持菜单和扫描，演示页也能找到对应的复算命令。

因此，我们交付的不只是一次计算结果，还包括可以替换输入继续研究的程序和记录。C测试覆盖13722项，另有50组CLI检查。CEA与NASA9数据同源，这些证据主要支持软件与方法一致性，实验和实机标定仍需补充。

## P12 B：收尾（50秒）

我们完成了两型动力方案研究，并用C语言把燃烧、推进剂、喷管和循环的性能分析连起来。几组结果说明：温度最高不等于c*最高，比冲与推力要分别解释，喷管收益要同时看面积与背压，循环还要满足整机收支。

这些判断都有明确输入和复算依据。下一步是在这套方法上补充同批实机参数、冷却和结构约束，让条件研究进一步接近真实设计。我们的汇报到这里，谢谢老师同学，欢迎提问。

## 5分钟问答：短答与备查

先由负责该半场的人回答，另一人只补必要条件。先说明问题中的固定量，再回答结论。单题争取45–60秒；没有参数时说明缺口，不临时填数。

| 可能问题 | 可以直接用的短答 |
|---|---|
| 你们的主要优势是什么？ | 把型号资料、输入假设、C计算、结果解释与核验对应起来；液体焓、变比热、循环收支和域判据都有明确实现，不只报单点性能。 |
| O/F2.7就是最佳设计点吗？ | 是当前入口与采样网格的c*峰。任务最优还要考虑密度、贮箱、冷却、结构和循环，不能直接等同。 |
| 为什么甲烷比冲更高，推力没有明显增加？ | 固定PcAt时F由CF决定，流量由c*决定，两个量变化不同。燃料仍可以通过组成和热性质影响CF。 |
| O/F3.4是富氧吗？ | 相对甲烷完全燃烧的化学计量O/F约4仍属富燃；相对c*峰2.7则更偏向氧侧，要说明参照。 |
| c*一定正比于√(T/M)吗？ | 这是固定γ等近似下的趋势关系；当前变比热和变组成模型还包含γ影响，以求解结果为准。 |
| 凝聚碳判据能预测积碳寿命吗？ | 它只判断石墨热力学稳定性，不给沉积速率、位置或寿命。a_C≤1也不证明所有遗漏物种都能忽略。 |
| 喷管拒算是否说明已发生分离？ | 说明pa超过理想pe，超出当前附着模型接受域；实际分离位置和侧载还需更具体模型。0.4pa只是经验参考。 |
| 补燃是不是一定比开式好？ | 本次两情景同时改变燃料、O/F和泵压，无法隔离循环因果。当前能比较闭合关系，优劣需同条件和任务约束。 |
| 涡轮出口压力都求解了吗？ | 开式0.8MPa是输入，补燃17.947MPa在返回压力约束下通过轴功反解，迭代27次。 |
| HP能算燃烧室压降吗？ | HP在给定压力下求定焓平衡，不预测燃烧室压降。 |
| 喉部为什么M=1？ | 当前模型采用稳态阻塞流动前提，施加M=1再解喉温，不是证明任意流动都阻塞。 |
| 元素势法有几个未知数？ | 当前CHO是三个元素势加总摩尔量，共4个；扩展CHON时是四个元素势加总量，共5个。 |
| 实际CF要减多少？ | 没有统一百分比，应由具体黏性、分离、非平衡损失模型或试验支持。 |
| 多台发动机推力能直接相加吗？ | 先按摇摆方向投影，并说明忽略发动机间耦合的条件，不能无条件标量相加。 |
| CEA对上是否等于真实发动机准确？ | 同源数据对照检查方法与实现，不能代替实验、部件图谱或整机标定。 |
| 计算速度做过什么改进？ | HP外层采用保持夹逼的Illinois法和热启动，归档310输入在当前主机约6.4倍提速；这不是所有工况的通用保证。 |

## 练习方式

第一遍完整朗读并实际切屏计时，不追求背熟；在时间表标出停顿和超时。第二遍每页只看三句提示讲，删掉重复解释。第三步用上表抽问，练习先回答结论再补条件。最终页面和讲稿一起调整，不能只靠加快语速挤进15分钟。
