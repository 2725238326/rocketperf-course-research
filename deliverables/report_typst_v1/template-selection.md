候选还包括 [modern-nju-thesis](https://github.com/nju-lug/modern-nju-thesis) 和 [modern-sjtu-report](https://github.com/StellarLane/modern-sjtu-report)。前者面向学位论文，后者具有学校场景约定；本次十项课程报告采用用途更直接的课程报告模板。选定模板的 README、许可证和实际函数均已读取，并实际编译了正文；没有只依据模板名称判断适用性。

本次沿用此前已完成的 GitHub API 与源码核实结果，没有重新发起 Grok 调研，也没有通过浏览器 UI 检索。上游源码仅在项目 `build/` 中保留临时检出，本目录包含编译所需模板副本；原始说明字节副本为 `template/upstream-readme.txt`。

## 本地适配

正文实际调用上游 `project()`、`cover_report()` 和 `tlt()`，保留其编号、目录与三线表机制。修改记录在 [本地差异](template/LOCAL-ADAPTATIONS.patch)，涉及以下文件：

| 文件 | 改动及原因 |
|---|---|
| `template/covers.typ` | 在原报告封面函数中增加 `report6` 中性课程分支，显示课题、姓名、日期，保留正式居中层级及信息网格；该分支不展示浙江大学校名校徽；没有虚构本组学校身份 |
| `template/fonts.typ` | 将原字体名称映射到本机宋体、黑体、楷体、Times New Roman 与 Consolas，避免缺字回退 |
| `template/lib.typ` | 六位中文姓名以全角空格分隔；调整 A4 页边距、章节字号、正文行距；图表保持整体；移除正式报告中不需要的跳转图标及蓝色引用 |
| `template/math.typ` | 将已弃用的 `diff` 符号改为 `partial`，兼容 Typst 0.14 |
| `report.typ` | 使用中性封面；目录/摘要用罗马页码，正文独立从 1 起；摘要不占正文编号；章节 1—10 对应作业范围；增加图题、三线表、正文数字引用和完整原文网址 |

封面前空白页的原因是模板输出了页面辅助内容后又切换页面设置。本次移除封面函数内这次多余切换，在源文件层修复，没有裁切最终 PDF。

## 许可和依赖边界

MIT 仅说明所引用模板的许可，不为本项目整体代选对外许可证。模板自带的包与许可保持原状。Typst Preview 依赖版本由模板导入语句固定，本次实际使用 Typst 0.14.2；首次在新机器编译可能需要获取对应缓存。

本地适配满足本次课程报告的排版需要，不宣称满足某所学校未提供的专用规范。待获得具体校名或正式封面要求时，可在同一来源与版式体系内填写和调整。
