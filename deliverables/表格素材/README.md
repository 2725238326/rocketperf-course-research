## 最快放法

1. 打开目标PPT页，删掉模板样例表。
2. 选择“插入 → 图片 → 此设备”，选本目录对应PNG。
3. 拖四角调整大小，放到指南指定的左侧或中央区域。
4. 不要用侧边手柄拉伸。表格文字应能在放映视图中读清。

## 可编辑放法

1. 打开PPT可复制表格.xlsx。
2. 点击对应工作表，选上表中的区域，例如P8选A1:C5。
3. Ctrl+C，切回PPT后Ctrl+V。
4. 粘贴选项选“保留源格式”。如果粘成图片，撤销后使用“选择性粘贴”里的PowerPoint表格选项。
5. 在PPT里调整表格宽度、字号和颜色。PPT修改不会反写Excel。
