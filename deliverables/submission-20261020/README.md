## 使用

完整解压后，控制台版双击 `rocketperf-run.bat`；图形界面版双击
`rocketperf-gui.exe`，需要系统提供 Microsoft Edge WebView2 Runtime。
运行计算无须 Python、CEA 或编译器。编译说明随程序源码提供。

报告与演示稿保留参数条件、参考文献和组员分工。程序数值适用于所列
研究输入，不能直接作为两型真实发动机的实测性能或复用寿命结论。

## 整理与核验

PPT 提交副本修正母版占位文本、重复页码、循环入口表述及制作话术，
不改写原版；报告保持已定稿的正文和版式。源码与运行包不收录内部
任务板、协作提示、对话、历史备份、检索配置、编译缓存和日志。
数据来源、第三方许可证、物性表生成说明和必要模型限制随材料保留。

组包入口为 `tools/submission.py`，输入为 `tools/delivery.py` 生成并核验
的固定提交交付，以及经过结构和版面复核的 PPT 提交副本。
检查日志留在 `build/submission-checks-20261020/`；GUI 原生桌面视觉验收
仍按 GUI-001 单独记录，不将桥接测试说成原生窗口视觉验收。

本轮生成本地上传材料，未操作课程平台。
