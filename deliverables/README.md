# 汇报准备与制作入口

当前交付是讲解思路、稿子和逐页制作指导。由小组按指南组合PPT，再一起优化内容、图片和排版。展示15分钟，提问另计5分钟；两人分段主讲，P6结束后交接一次。组号、姓名与实际贡献稍后本人填写。

建议依次打开：

1. [逐页制作指南](ppt-structure.md)：原模板具体页码、复制顺序、每页可用文字、图片替换和图表制作步骤。
2. [讲解思路](presentation.md)：大作业成果与优势如何组织成一场完整论证。
3. [双人讲稿](defense-script.md)：逐页台词、指图动作、转场、交接和5分钟问答。
4. [图表数据](ppt-materials/README.md)：6份C结果数据，供手工建图和填表，拒算点不补假数。
5. [时间表](timing-chart.md)与[演示编排](demo-choreography.md)：13:45预算、75秒机动、操作分工、失败保底和待填实测栏。

研究依据：[报告](report.md)、[离线演示](demo/index.html)、[真实贡献待填表](contributions.md)。离线演示按1–6切页、A控制动画，页面显示预计算C数据，复算使用本地exe。历史截图保留于`demo/screenshots/`，使用前核对截图的实际输入。

先按原模板页序组合12页正文，确认图、文字、输入条件对应；下一轮再统一裁图、字号和密度，最后做两人实测演练。当前没有最终PPT交付，也不代表报告、人员贡献或最终四件套已经验收。
