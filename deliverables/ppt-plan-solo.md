依据：启动脚本、报告正文、PPT专用CSV和模板31。此文件给组装者逐页替换模板使用，不生成PPTX。所有计算数值均标为研究算例结果，不作两型火箭的实测性能。

## 总体结构

使用北京航空航天大学模板31，在副本中保留蓝白主色、北航校标、16:9比例和原有版式。主讲共14页：封面、12页正文、致谢；另附3页备答放在致谢后，不计时。单人连续讲述，不做现场交接；搭档只在问答环节回答富氧补燃问题。

展示预算13分30秒，另留1分30秒机动；问答另计5分钟。现场最多切换GUI三次，预留总计100秒操作时间。封面姓名、组号、指导教师、真实分工尚未确认，统一留待填写。GUI截图目录目前不存在，按下表保留截图文件名占位。

### P5 课程理论与计算顺序（T12）

四个流程位置：

1. 入口状态：温度、压力、化学焓与C/H/O元素库存
2. 燃烧室HP平衡：求温度、组成和c*
3. 冻结喷管：求喉部、出口、流量和推力
4. 独立整机入口：联合求分流、回流、涡轮功和主室状态，复用热化学与喷管模块

公式区：

ṁ = PcAt / c*

F = CF·Pc·At

Isp = CF·c* / g₀

公式旁的小字：

理想气体、固定γ近似下，c*随√(Tc/M̄)变化；本模型还计算变温物性和组分平衡，不能只按温度判断。

页面底部：

喷管推力项：F = ṁve + (pe − pa)Ae。背压改变压力推力；pa > pe时当前附着求解器拒算。

保留T12四个说明区，删除模板段落和容易被误读为串联程序依赖的波形装饰。前三项说明推力室路径，第四项注明独立整机入口；不要画成单喷管结果直接送入循环的单向链。公式保持可编辑文本；导航高亮“研究过程”。

来源：报告第2节；c*近似关系见报告第7.1节；拒算边界见报告第2、7.4节。

### B2 公式与控制体（T12）

标题：性能关系与质量边界。T12四个文字区分别填入以下原文，删除示例段落，公式用可编辑公式对象，导航高亮研究方法。

1. 定义：c*=PcAt/ṁ，CF=F/(PcAt)，Isp=F/(ṁg₀)。
2. 联立：ṁ=PcAt/c*，F=CF·PcAt，因此Isp=CF·c*/g₀。固定PcAt时，c*变化直接影响质量流量。
3. 背压：F=ṁve+(pe−pa)Ae。同一理想出口状态下，背压增加使压力推力下降；当前附着模型在pa>pe时拒算。
4. 循环边界：开式的主喷管流量与外排流量之和为总供给；补燃回流属于内部流，不再计为第二次外部供给。

页脚：报告第2、7.6节。g₀=9.80665 m/s²；公式中的流量与推力必须来自同一个控制体。
