# PPT逐页制作指南：北航模板31

小组使用指定文件：[北京航空航天大学模板-31.pptx](../PPT/PPT/【第2步】PPT模板文件（真正使用）/北京航空航天大学模板-31.pptx)。模板31为23页、16:9，顶部导航依次是“绪论背景、研究内容、研究方法、研究过程、结果分析”。本指南把它改成13页正文＋1页致谢，展示15分钟，提问另计5分钟。A讲P1–P7，B讲P8–P13，P7结束交接一次。

本文件只指导小组制作PPT，不替你们生成最终PPT。先按页码和文字完成第一版，再检查图片、字号、数字与讲稿。

## 一、先建立模板31的工作副本

1. 打开模板31，立即“另存为”`两型火箭动力系统_汇报.pptx`，不要修改原模板。
2. 最终使用顺序为：**P1=T1 → P2=T4 → P3=T8 → P4=T10 → P5=T12 → P6=T13 → P7=T15 → P8=T16 → P9=T17 → P10=T15(复制) → P11=T13(复制) → P12=T19 → P13=T17(复制) → P14=T23。**
3. 不使用T2目录、T3/T6/T9/T11/T14/T18章节封面、T20参考文献、T21原致谢、T22个人介绍。制作文件只保留上面14页。
4. 先复制T15、T13、T17各一份，再按最终顺序拖动缩略图。不要把重复页误当成不同内容页。
5. 删除所有模板示例英文、日期`2025-02-21`、`XXX`、示例论文题目、示例照片说明和“这里可以输入你的论文题目”。保留北航校标、蓝色导航和蓝白主色。
6. 顶部导航中的文字改为：**绪论背景｜研究内容｜研究方法｜研究过程｜结果分析**。各页把当前所属栏目加深或加粗，尽量在母版中改一次。
7. 正文18–22pt，图表标注不低于16pt，底部条件说明14pt。模板已有图片只在与页面内容匹配时保留，示例校园照片不能当研究证据。

## 三、逐页填法

### P1 封面（T1）

保留北航建筑照片和校标，删除模板毕业论文英文副题及无关校训。大标题改为：

**两型运载火箭动力系统性能研究**

副题改为：

**朱雀三号与长征十号乙：燃烧、喷管与循环的C语言计算**

把答辩学生、组号、指导老师和日期改成可编辑占位：

`答辩学生：［待填写］、［待填写］　组号：［待填写］　指导老师：［待填写］　2026年10月16日`

“XXX学院”改成`火箭发动机原理课程大作业`。封面不放测试数量和公式。

### P2 构型、任务与输入缺口（T4）

标题改为：**两型火箭：构型不同，性能关注点也不同**。

蓝底正文替换为：

`朱雀三号与长征十号乙的公开资料能够确定部分级段构型、推进剂和发动机配置，但同批单机室压、喉面积、面积比、入口状态和循环分流等输入并不完整。我们把已核对事实与研究输入分开，在明确假设下比较设计因素。`

底部三个关键词卡片改为：

1. `四个级段`：两型火箭一、二级
2. `两类任务环境`：一级起飞背压；二级低背压与再起动
3. `输入可替换`：缺失参数保留为研究输入，不拼接不同批次

### P3 我们研究什么、交出了什么（T8）

T8顶部三张示例校园照片建议替换为：左侧四级段资料或构型表，中间`docs/architecture/components.svg`模块架构局部，右侧[p6-cstar.png](ppt-materials/figures/p6-cstar.png)曲线局部。底部四个编号卡片改为：

1. **研究对象**：四个级段的构型、能力和参数来源
2. **研究问题**：混合比、推进剂、喷管、背压和循环分配
3. **已有基础**：C17热化学、喷管、循环模块及保存记录
4. **产出成果**：可运行程序、条件性结果、改进判断与核验

页底加粗：**把课程理论落成可替换输入、自动计算、可解释结果的程序。**

### P4 两条计算路径（T10）

删掉两张示例建筑照片，改为左右两张文字卡片。左卡标题**推力室路径**，正文：

`入口温度/压力 → 入口焓与C/H/O库存`

`HP平衡 → 燃烧温度与九气相组成`

`冻结喷管 → 流量、推力、比冲`

右卡标题**整机循环路径**，正文：

`泵压、效率、支路和回流条件`

`预燃室、涡轮、主室联合计算`

`质量、元素、轴功、焓流闭合`

两卡之间加：**推力室是性能入口，循环是部件联合入口；两者按各自输入边界调用公共热化学与喷管模块。**

### P5 计算过程（T12）

四个说明位置依次写：

1. **入口状态**：推进剂温度、压力 → 入口焓与C/H/O库存
2. **燃烧室平衡**：给定Pc的定焓定压HP → 温度、组成、c*
3. **冻结喷管**：燃烧室组成冻结膨胀 → 喉部、出口、流量与推力
4. **整机循环**：泵、预燃室、涡轮、主室 → 外排/回流与功率收支

底部放：`ṁ = PcAt / c*`　　`F = CF·Pc·At`　　`Isp = CF·c*/g₀`。

公式下面加粗：**后面的每个结果，都先看固定了什么，再看改变的是c*、CF还是循环分配。**

### P6 C17程序架构与工程质量（T13）

删除电脑里的校园照片，插入[代码模块架构图](../docs/architecture/components.svg)；如果整图字太小，裁剪`thermo → nozzle → cycle → output`主链。右侧标题：**C17程序：从输入到结果的六个职责**。

六条短句：

- **输入输出 1686行**：INI校验、文本/JSON结果
- **热化学 1408行**：NASA9物性、HP平衡、液体入口焓、石墨活度
- **冻结喷管 922行**：喉部阻塞、膨胀、背压域评估
- **整机循环 962行**：泵、预燃室、涡轮、主室与外排/回流
- **命令行菜单 1484行**：单点、扫描、对比和8项菜单
- **数值与错误 165行**：状态码、失败保持原输出、越域拒算

页脚写：`C17严格编译（-Werror）｜13722项C检查+50组CLI｜HP Illinois+热启动约6.4倍提速`。

### P7 燃烧结果（T15）

### P10 背压与适用域（复制T15）

### P12 改进判断与下一步（T19）

## 五、组合后检查

第一轮检查14页顺序、标题、页脚条件、图表和关键数字。第二轮删除所有模板示例文字、英文长段和多余照片。第三轮统一字号、导航高亮、图片裁切和对齐。最后按[讲稿](defense-script.md)计时：A讲P1–P7，B讲P8–P13，P7最后10秒完成交接。

备答页先不做。需要时复制T16/T17/T19，放共同输入、c*/CF公式、碳判据、多背压曲线、循环完整输入和理论问答。
