# 现有截图与替换指导

本目录的六张PNG是历史默认态素材，不代表当前PPT页面，也不能证明已完成演练。最终页面由小组按[逐页指南](../../ppt-structure.md)组合，再共同优化。

| 现有文件 | 可取用的区域 | 使用前核对 |
|---|---|---|
| p5_chamber.png | 燃烧室曲线、产物或判据图区 | 当前O/F与所标数字一致；正文c*曲线优先用CSV重画 |
| p6_propellant.png | 两种方法的比较图 | 正文采用2.6/2.6、ε10、真空 |
| p8_nozzle_refusal.png | 喷管示意与拒算状态 | 正文需改到液甲烷O/F2.6、ε40、海平面后重新截取；不能套旧状态 |
| p9_cycle.png | 开式循环中央管路 | 确认是开式，涡轮0.8MPa为输入；截图只截部件和主/支路 |
| p11_cea.png | 参考对照细节 | 供追问时使用，不把整个页面缩进正文 |
| p11b_engineering.png | 工程检查细节 | 软件检查与科学验证分开解释 |

截图时关动画，裁去浏览器工具栏和无关控制区，保留图区标题、必要单位及当前工况。适当放大网页再截，先保证投影可读，不以PNG字节数判断质量。

可选关键态：演示页1点“发生器1.0”后再点“凝聚碳区”（实际O/F0.8）；演示页4切到补燃并点涡轮查看17.95MPa求解结果。质量/元素相对残差无W单位，只有轴功与焓流残差用W。截图不足时可先用制作指南里的表格，不必为补图卡住正文组合。
