# 展示大纲与讲稿（10分钟版 · 叙事线：一个问题，一条证据链）

展示内容草稿；尚无最终PPT和实测讲述时长。数字按输入、归档和报告核对；人员分工待本人确认。
总时长按 9 分钟主讲 + 1 分钟弹性设计，共 10 页。

叙事主线：**公开资料的两型发动机 → 缺什么输入 → 用课程理论在声明假设下算 → 三个能解释取舍的结果 → 小组的判断。**

## P1 封面（约20秒）

- 标题：重复使用运载火箭动力系统性能研究——朱雀三号与长征十号乙
- 副题：从公开资料到 C 语言热化学计算的条件性结论
- 组号/组员/日期

**讲稿**：各位老师同学好。我们组研究朱雀三号和长征十号乙的动力系统：公开资料给了构型，没给性能参数；我们用课程理论把中间缺的部分算出来，并说明每一步依赖什么假设。

## P2 问题：两型发动机，我们知道什么、缺什么（约60秒）

- 表格：四个级段 ×（构型/推进剂/台数/已知动作）
  - 朱雀三号遥一一级：9台TQ-12A、液氧甲烷、整箭起飞推力7542 kN、起飞质量约560 t
  - 朱雀三号遥一二级：1台TQ-15A真空型、二次起动
  - 长征十号乙首飞一级：液氧煤油、7台百吨级（5台可摇摆/二次起动、2台固定）、网系捕获回收
  - 长征十号乙首飞二级：液氧甲烷、140吨级推力量级描述
- 右侧：缺的输入——单机室压、喉部面积、面积比、主室O/F、入口状态、循环细节
- **本页即研究动机**：构型能查到，性能卡拼不出来 → 只能在声明假设下做条件性计算

**讲稿**：资料给出朱雀三号一级9台液氧甲烷发动机、二级1台真空型；长十乙一级是7台百吨级煤油机、二级是甲烷。但同批单机的室压、喉面积、混合比、入口状态都没有公开——这决定了我们工作的性质：把课程的热化学、喷管、循环理论做成可复算的C程序，在声明假设下计算，结论全部带条件。

## P3 方法：输入焓与元素库存 → HP平衡 → 冻结喷管 → 循环闭合（约60秒）

- 使用[计算入口流程图](../docs/architecture/report-flow.svg)或 live panel 截图
- 三个要点：C17纯计算核心、失败显式返回不输出假结果、同一输入不因入口不同而不同

**讲稿**：程序核心是C17。给定入口焓和元素库存，求九气相定焓定压平衡得燃烧室状态；冻结喷管从声速喉部膨胀到给定面积比；循环模型再闭合质量、轴功和焓三本账。所有失败显式返回，不输出假结果。方法细节和验证放最后回答，先把时间给结果。

## P4 结果一：推进剂取舍——比冲与推力必须一起看（约70秒）

- **先给结论**：同条件下甲烷比冲高13.85 s、推力低343.6 N——这是同一枚硬币的两面
- 机制图：`mdot = Pc·At/c*`，c*高→流量降→推力降；Isp = F/(mdot·g0) 同时升
- 数据表：Pc=10 MPa、At=0.01 m²、面积比10、真空、O/F=2.6，甲烷324.43 s/172.64 kN，RP-1 310.57 s/172.98 kN
- **条件**：两推进剂O/F、入口状态不同（方法成对比较，非燃料排名）

**讲稿**：第一个结果是推进剂取舍。同一室压、喉面积、几何和背压下，甲烷方法比冲高13.85秒，但推力低343.6牛。原因是固定喉面积时质量流量等于Pc·At除以c*：甲烷的c*更高，流量下降，推力随之降低。所以选推进剂不能只看比冲：起飞段推力敏感的任务，这344牛的差距要和14秒的比冲收益一起权衡。注意这是方法层面的成对比较，两种燃料的入口身份各自保留。

## P5 结果二：喷管面积比——收益递减，代价加速（约70秒）

- **先给结论**：面积比10→20→40，比冲增益13.05→10.37 s；每平方米换来的比冲从38.5降到15.3 s/m²——腰斩
- 图：双轴图（比冲 vs 面积比；出口面积 vs 面积比）
- **条件与边界**：5 kPa背压下损失1.75→6.93 s；出口面积翻四倍；长度/质量/冷却未算

**讲稿**：第二个结果是喷管面积比。三个计算点显示增益递减：10到20增加13秒，20到40只增加10.4秒，但出口面积从0.34扩到1.36平方米。按单位面积算，后半段每平方米只换15秒，是前半段的四成。同时背压损失随面积比增大。所以大喷管只对真空任务剖面有明确意义，受级段直径约束的设计要在这个收益/代价比上做取舍。

## P6 结果二续：海平面过膨胀——同一枚喷管，两个世界（约50秒）

- **先给结论**：面积比40在海平面 pa/pe≈6.07 远过膨胀；该背压匹配面积比约9.92；真空收益与海平面匹配差23.4 s
- regime 评估表（理想pe、匹配面积比、0.4pa经验参考线）
- **条件**：定比热情景，0.4pa是经验参考不是分离预测

**讲稿**：同一枚面积比40的喷管，在海平面远过膨胀——理想出口压力只有背压的六分之一。域评估给出的匹配面积比约9.9，和面积比40之间的真空比冲差23秒。这就是一级发动机面对的取舍：按海平面匹配设计还是保留真空收益。这页用定比热情景说明量级，regime接口给出的是经验参考线，不预测分离位置。

## P7 结果三：开式与补燃循环如何闭合（约75秒）

- **先说清前提**：两情景燃料、混合比、泵压都不同——这是两个各自的闭合检查，不是对比实验
- 共同输入：总供给100 kg/s、主室10 MPa、主喷管面积比8、海平面背压
- 开式：CH4/O2，支路1.934 kg/s外排贡献2.636 kN（不能漏记）；整机290.539 kN、296.268 s
- 补燃：RP-1替代物，回流74.630 kg/s与新鲜燃料25.370 kg/s混合；涡轮出口17.947 MPa > 11 MPa下限；整机285.497 kN、291.126 s
- 检查：两处燃烧Q=0、元素库存、质量流量、轴功残差 < 1 W

**讲稿**：第三个结果是循环闭合。先说明：两个情景的燃料和供给压力不同，所以我们不做循环优劣比较，看的是各自的账能不能闭上。开式循环有1.934公斤每秒的支路外排，它仍贡献2.636千牛推力，漏记就会低估性能。补燃循环把74.6公斤每秒回流燃气与新鲜燃料混合，轴功平衡求出的涡轮出口压力17.9兆帕，高于注入主室所需的11兆帕下限——功率账成立。两列的残差都在1瓦以内。

## P8 判断：小组的四条取舍意见（约60秒）

- 1. 推进剂选择必须同看比冲与推力（P4）
- 2. 面积比20以上收益/代价比腰斩（P5）
- 3. 海平面匹配与真空收益差23.4 s，一级喷管的量级取舍（P6）
- 4. 外排必须计入推力账，+1406.9 N（P7）
- 每条标注输入条件；换输入即需重算

**讲稿**：综合这些计算，小组提出四条判断：第一，推进剂选择不能只看比冲，推力代价要同表呈现；第二，面积比20以上单位面积收益腰斩；第三，海平面匹配与真空收益之间是23秒量级的取舍；第四，外排流量必须计入推力账。每条判断都标注了输入条件，替换输入就要重新计算。

## 提问预案（Q&A，5分钟）

| 可能问题 | 回答要点 |
|---|---|
| 为什么不做真实发动机性能？ | 当前已核验来源未组成同一构型与工况的完整输入卡；逐项缺口与影响见参数台账，计算保留声明假设 |
| 和CEA比差在哪？ | 同源物性、不同实现；连续液体和RP-1各按档案范围报告差值，不能统称≤0.02K或证明全域正确；CEA还支持更多产物、凝聚相和平衡喷管 |
| 0.004406 K是什么口径？ | 燃烧室HP温度的最大差；全字段最大差是喉部截面0.005602 K（fuel_hot工况），两者都在CEA打印精度以内 |
| 煤油怎么处理的？ | 固定RP-1锚点方法研究，限定域；富燃域九气相奇异/凝聚碳已登记为边界；国产煤油组成未知，不绑定型号 |
| 0.4pa分离判据可靠吗？ | Summerfield型经验提示，给"参考线"不是预测；真实分离受激波/边界层/喷管型面影响，超出模型范围，报告全程标注 |
| 循环旧版为什么拒绝回流？ | 旧`prescribed_thermal_cycle_v1`只有给定热状态外排，仍拒绝回流；新`adiabatic_single_shaft_cycle_v1`另行闭合假设回流的元素、焓、轴功和压力，但不等于实机标定 |
| 比冲高推力低矛盾吗？ | 固定Pc/At时mdot=Pc·At/c*；较高c*使流量下降，需同时比较F=mdot·g0·Isp |
| 为什么用C不用Python？ | 课程要求核心计算C语言；C核心无I/O依赖可移植，Python只用在测试与治理工具 |
| 验证是独立实验吗？ | 没有发动机实验数据。保存的CEA卡使用同源物性，检查的是这些输入下的软件结果；构建检查不能提升物理证据等级 |
