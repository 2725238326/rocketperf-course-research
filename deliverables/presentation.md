# 汇报思路：把成果、优势和证据讲清楚

当前工作是讲稿与PPT制作指导，小组按[逐页指南](ppt-structure.md)组合后再优化。展示15分钟，提问另计5分钟；A讲P1–P6，B讲P7–P12，只交接一次。姓名与贡献稍后本人填写。

## 全场要让老师记住什么

**我们围绕两型运载火箭的动力系统，把课程理论做成了可运行的C程序，并用同条件比较说明燃烧、推进剂、喷管和循环的设计取舍。**

这句话同时回答“研究什么”“做成什么”“算出了什么意义”。公开型号事实、研究假设和计算结果各自说明，但不要把每页都讲成模型限制清单。

## 成果与优势怎样落到证据

| 要介绍的成果/特点 | 观众能看到的证据 | 对应页 | 表述范围 |
|---|---|---|---|
| 两型方案研究按级段展开 | 四个级段的构型、推进剂和能力对照 | P2 | 同批资料能支持的事实，未知参数单列 |
| 课程理论用C自动计算 | 入口、平衡、冻结喷管与整机循环两条路径 | P3–P4 | C17核心独立运行；工程/验证工具另列 |
| 燃烧分析超过只看温度 | c*峰与温度峰不同，富燃端a_C拒算 | P5 | 采样峰、九气相与凝聚碳判据 |
| 比较说明固定条件和机制 | 同Pc/At/几何/背压，Isp、流量、推力分别比较 | P6 | 两种指定入口方法，非实机燃料排名 |
| 改进讨论同时算收益与代价 | 两段单位出口面积收益、同几何背压差 | P7–P8 | 未计结构质量、冷却或实际分离 |
| 整机收支形成可核对结果 | 外排/回流、轴功与压力约束、残差单位 | P9 | 两个不同输入情景，不隔离循环因果 |
| 研究结论回到作业对象 | 四级段的条件性改进判断 | P10 | 不能替代真实性能卡 |
| 结果可复算、程序可用 | 参考对照、输入输出、菜单与扫描 | P11 | 软件方法核验，非实验标定 |

“优势”用具体问题表达：引入液体焓与变比热，使理论处理更具体；用同条件比较，使结论的原因可解释；用守恒和域判据，使输出可检查；保存输入与命令，使结果可复算。避免只说“代码多、测试多、功能多”。

## 每页在论证中的角色

| 页 | 本页解决的问题 | 进入下一页的理由 |
|---|---|---|
| P1 | 研究对象与目的 | 先看两型方案差别 |
| P2 | 四个级段有什么不同 | 这些问题需要哪些工作 |
| P3 | 我们做成了什么 | 工作靠什么方法实现 |
| P4 | 性能参数怎样算 | 先看燃烧室结果 |
| P5 | 为什么温度峰不等于c*峰 | 不同推进剂如何比较 |
| P6 | 为什么比冲提高、推力近似不变 | 继续固定推进剂，研究几何；在此交接 |
| P7 | 大喷管得到多少、付出多少面积 | 还必须考虑背压 |
| P8 | 同几何背压损失及适用域 | 整机还要为泵提供功率 |
| P9 | 外排与回流怎样进入整机收支 | 把结果用于具体级段判断 |
| P10 | 有计算依据的改进意见 | 这些判断依据何种核验 |
| P11 | 结果可信到什么程度、怎样复算 | 收束成果与下一步 |
| P12 | 这项工作留下了什么 | 进入5分钟问答 |

## 主讲的讲述规则

每页先说结论，再指图上的一个位置解释，最后给下一页的理由。表格不逐格读，主要数字只读一到两个。解释时先说固定量，再说变化量。边界贴着对应结论讲一句，详细推导与方法域留问答。

先按完整[双人讲稿](defense-script.md)练，之后把每页缩成三句提示。A/B交接不用重新介绍项目，B直接沿用P6的输入进入几何研究。演示由另一人操作，主讲不断句。实测与删减见[时间表](timing-chart.md)，操作见[演示编排](demo-choreography.md)。
