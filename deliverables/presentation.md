## P1 封面（约20秒）

- 标题：重复使用运载火箭动力系统性能研究——朱雀三号与长征十号乙
- 副题：从文献调查到 C 语言热化学计算
- 组号/组员/日期

**讲稿**：各位老师同学好，我们组研究朱雀三号和长征十号乙的动力系统。下面依次说明资料中能确认的构型、程序在给定输入下算出的结果，以及这些结果适用到哪里。

## P2 研究对象：两型动力系统（约60秒）

- 表格：四个级段 ×（构型/推进剂/台数/已知动作）
  - 朱雀三号遥一一级：9台TQ-12A、液氧甲烷、整箭起飞推力7542 kN、起飞质量约560 t；遥一软着陆未成功
  - 朱雀三号遥一二级：1台TQ-15A真空型、二次起动
  - 长征十号乙首飞一级：液氧煤油、7台百吨级（5台可摇摆/二次起动、2台固定）、整箭推力原文约890/900吨级（吨力口径）、网系捕获回收
  - 长征十号乙首飞二级：液氧甲烷、140吨级推力量级描述，不是完整单机性能卡
- 配图建议：两型构型示意（引用来源标注）

**讲稿**：研究对象是朱雀三号遥一和长十乙首飞构型。资料给出朱雀三号一级9台天鹊-12A、二级1台真空型天鹊-15A；长十乙一级使用液氧煤油、7台百吨级发动机，二级使用液氧甲烷。多次起动和回收动作按对象和版本分别记录。当前程序是稳态模型，不能检验起动过程或回收可靠性。

## P3 关键约束：公开数据决定研究定位（约45秒）

- 左：能查到的——构型、推进剂、台数、整箭级推力
- 右：现存已核验原文尚未凑齐的一致输入——单机室压、喉部面积、面积比、主室O/F、入口状态、循环细节
- 本页说明影响计算的缺项；具体假设在算例页列出

**讲稿**：已保存的原文还不能为同一构型、级段和工况建立完整输入卡。缺少的量包括室压、喉部面积、面积比、主室混合比和入口状态。两型原文的核验截止10月3日，产品与专题资料使用各自日期。下面的算例是带输入假设的方法计算，不是型号实测值。

## P4 程序入口与计算支路（约60秒）

- 使用[计算入口流程图](../docs/architecture/report-flow.svg)，与报告第5节相同
- 标注：C17纯核心、Windows发布版、失败显式返回

**讲稿**：程序叫rocketperf，计算核心用C17实现。热化学使用NASA9数据，燃烧室求定焓定压平衡，冻结喷管从喉部求到出口。程序保留两个循环模型：一个把温度作为输入并记录外排循环所需热量；另一个从入口焓和元素库存求Q=0的开式或补燃情景。交互菜单、算例文件和命令行调用对应的C接口。演示使用本地已测构建。

## P5 核心算法（约60秒）

- 左：HP平衡 = 元素库存守恒 + 九气相平衡闭合 → 绝热温度+组成
- 右：冻结喷管 = 组成沿程不变、比热随温变；声速喉部→阻塞流量→面积比求出口
- 底部：TP平衡用Newton迭代、解析Jacobian与主元消去；HP外层和喷管用二分夹逼，另查守恒残差与有效域

**讲稿**：物性库有10种气体，当前CHO平衡选其中9种，N2未参加这个平衡系统。TP组成求解用Newton迭代、解析Jacobian和主元消去；HP外层以温度夹逼焓残差。冻结喷管沿程保持组成，比热随温度变，以声速条件和面积比求喉部及出口；这部分也用夹逼求根。残差和有效域检查失败时显式返回，不输出假结果。

## P6 验证范围（约50秒）

- 并列展示三种检查：公式/守恒，CEA同源软件对照，构建/交付检查；三者回答不同问题
- 连续液体：47次C运行/18张参考卡，最大ΔT约0.004406 K、Δc*约0.003504 m/s；RP-1：33次运行/21张参考卡，原限定域和扩展点分别解释
- 来源说明：CEA采用同源物性，没有独立发动机实验

**讲稿**：先检查解析关系、守恒、非法输入和失败输出，再做CEA同源对照，最后检查构建和交付包。连续液体47次C运行对应18张CEA参考卡，最大温差约0.0044K；RP-1限定域按0.02K门限核验，扩展产物点另有0.31至0.46K差异。测试断言数不等于独立物理工况数。同源软件对照只支持保存范围内的方法一致性，不是独立实验。

## P7 算例一：液态甲烷基线与推进剂对比（约60秒）

- 基线卡：Pc=10 MPa、O/F=3.4、面积比10、真空 → T=3602.8 K、c*=1811.0 m/s、F=173.7 kN、Isp=320.8 s
- 对比条：另一个算例采用甲烷/RP-1各O/F=2.6，同Pc=10 MPa、At=0.01 m²、面积比10、真空：甲烷Isp +13.85 s、推力 −343.6 N
- 同喉面积下甲烷比冲高、推力低；两个量需要同时报告

**讲稿**：液态甲烷基线使用10MPa、O/F 3.4、喉面积0.01平方米、面积比10和真空，温度3602.8K、比冲320.8秒。成对比较使用另一张输入卡：两种推进剂的O/F均为2.6，室压、喉面积、几何和背压相同，入口身份分别保留。在这组条件下，甲烷比冲高13.85秒、推力低343.6牛。这个差值只属于这张输入卡。

## P8 算例二：开式与补燃如何闭合（约75秒）

- 共同输入：总供给100 kg/s、主室10 MPa、主喷管面积比8、海平面背压。两列燃料/O-F/泵后压力不同，完整输入表见报告7.6。
- 开式：CH4/O2；支路1.934 kg/s外排，主路98.066 kg/s；外排轴向推力2.636 kN；整机290.539 kN、296.268 s。
- 富氧补燃：RP-1指定替代物；回流74.630 kg/s与新鲜燃料25.370 kg/s混合；求得涡轮出口17.947 MPa，大于11 MPa注入下限；整机285.497 kN、291.126 s。
- 检查：两处燃烧Q=0、元素库存、质量流量和轴功；不比较这两列的循环优劣。

**讲稿**：这里检查两种循环的物料和功率账。开式有约1.934公斤每秒的支路外排，这部分仍产生2.636千牛推力。补燃把74.630公斤每秒回流与25.370公斤每秒新鲜燃料混合，总消耗仍是100公斤每秒；轴功求得的涡轮出口压力17.947兆帕，高于11兆帕注入下限。主室和预燃室温度由入口焓求出，热交换设为零。两列用了不同燃料、混合比和泵后压力，不能按比冲高低判定循环优劣。

## P9 算例三：改进研究——收益与代价一起算（约60秒）

- 面积比10→20→40：比冲增益依次13.048/10.365 s，新增出口面积依次0.3389/0.6778 m²；说明这两段取舍
- 支路排气投影+1：推力+1406.9 N、比冲+1.43 s——发动机计账不能漏外排
- 入口焓升：比冲+0.28 s但推力−9.7 N——单看比冲会误判

**讲稿**：给定热状态情景中，面积比10到40使真空比冲增加约23秒，出口面积扩大四倍，5kPa背压下的损失也增加。这三点不能推出真实喷管尺寸。支路轴向投影从0改为1时，模型推力增加约1407牛；连续液体固定喉面积的入口焓响应中，比冲略升而推力略降。三组计算的输入和流量约束不同，不能拼成一个发动机改装收益。

## P10 结论、边界与分工（约50秒）

- 结论三条：构型资料按版本整理；C17程序完成所列热化学、喷管和循环入口；改进算例同时报告收益、代价和适用条件
- 边界四条：无激波/分离/侧载；煤油仅固定替代物方法研究；新循环为条件性原型、缺实机部件特性；无独立实验验证
- 分工一行（见贡献记录）

**讲稿**：资料支持按构型和级段讨论两型方案，但不足以建立一致的真实单机输入卡。C17程序完成本报告使用的物性、平衡、冻结喷管和两类循环入口；结论只对相应输入成立。补燃模型没有实机泵、冷却、国产煤油批次、瞬态或独立整机实验数据。组员贡献还要由本人确认。

## 演示预案（可替换P7–P8，约90秒）

若评委要求现场演示，用发布版 exe：

1. 双击发布包中的 `rocketperf-run.bat` → 菜单 → 选择8和1–5 → 读取车辆研究情景结果。
2. `rocketperf nozzle regime cases\research\s3_sealevel_regime.ini --text` → 过膨胀域评估表。
3. `rocketperf cases` → 展示可复跑算例列表。

循环演示可替换P7–P8：选择朱雀三号一级和长十乙一级，展示预燃室HP、支路/回流流量、涡轮出口压力、轴功和残差。两组入口假设不同，不能比较Isp或推力高低；长十乙一级的家族补燃证据也不等于首飞子型性能卡。运行命令和输入见[循环验证文档](../docs/engine-cycle-validation.md)。

演示时说明选择了哪份输入。菜单8读取已有INI，不要求现场重填全部参数；JSON便于核对数值，`--text`便于讲解。过膨胀诊断可作备用内容，结果和限制见报告7.4。

## 提问预案（Q&A，5分钟）

| 可能问题 | 回答要点 |
|---|---|
| 为什么不做真实发动机性能？ | 当前已核验来源未组成同一构型与工况的完整输入卡；逐项缺口与影响见参数台账，计算保留声明假设 |
| 和CEA比差在哪？ | 同源物性、不同实现；连续液体和RP-1各按档案范围报告差值，不能统称≤0.02K或证明全域正确；CEA还支持更多产物、凝聚相和平衡喷管 |
| 煤油怎么处理的？ | 固定RP-1锚点方法研究，限定域；富燃域九气相奇异/凝聚碳已登记为边界；国产煤油组成未知，不绑定型号 |
| 0.4pa分离判据可靠吗？ | Summerfield型经验提示，给"参考线"不是预测；真实分离受激波/边界层/喷管型面影响，超出模型范围，报告全程标注 |
| 循环旧版为什么拒绝回流？ | 旧`prescribed_thermal_cycle_v1`只有给定热状态外排，仍拒绝回流；新`adiabatic_single_shaft_cycle_v1`另行闭合假设回流的元素、焓、轴功和压力，但不等于实机标定 |
| 比冲高推力低矛盾吗？ | 固定Pc/At时mdot=Pc·At/c*；较高c*使流量下降，需同时比较F=mdot·g0·Isp |
| 为什么用C不用Python？ | 课程要求核心计算C语言；C核心无I/O依赖可移植，Python只用在测试与治理工具 |
| 验证是独立实验吗？ | 没有发动机实验数据。保存的CEA卡使用同源物性，检查的是这些输入下的软件结果；构建检查不能提升物理证据等级 |
