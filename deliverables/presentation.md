## P1 封面（约20秒）

- 标题：重复使用运载火箭动力系统性能研究——朱雀三号与长征十号乙
- 副题：从公开资料到 C 语言热化学计算的条件性结论
- 组号/组员/日期

**讲稿**：各位老师同学好。我们组研究朱雀三号和长征十号乙的动力系统：公开资料给了构型，没给性能参数；我们用课程理论把中间缺的部分算出来，并说明每一步依赖什么假设。

## P2 问题：两型发动机，我们知道什么、缺什么（约70秒）

- 表格：四个级段 ×（构型/推进剂/台数/已知动作）
  - 朱雀三号遥一一级：9台TQ-12A、液氧甲烷、整箭起飞推力7542 kN、起飞质量约560 t
  - 朱雀三号遥一二级：1台TQ-15A真空型、二次起动
  - 长征十号乙首飞一级：液氧煤油、7台百吨级（5台可摇摆/二次起动、2台固定）、网系捕获回收
  - 长征十号乙首飞二级：液氧甲烷、140吨级推力量级描述
- 右侧：缺的输入——单机室压、喉部面积、面积比、主室O/F、入口状态、循环细节
- **本页即研究动机**：构型能查到，性能卡拼不出来 → 只能在声明假设下做条件性计算

**讲稿**：资料给出朱雀三号一级9台液氧甲烷发动机、二级1台真空型；长十乙一级是7台百吨级煤油机、二级是甲烷。但同批单机的室压、喉面积、混合比、入口状态都没有公开。这决定了工作的性质：不是去猜型号性能，而是把课程的热化学、喷管、循环理论做成可复算的程序，在声明假设下回答“这些设计取舍由什么决定、量级多大”。

## P3 我们做了什么：四个工作点（约60秒）

- **完整的计算链，全部C17实现**：液体入口焓与元素库存 → 九气相HP平衡 → 冻结喷管 → 循环闭合；运行时不依赖CEA或Python
- **越域显式拒算**：过膨胀、O/F超域、推进剂方法域外直接返回失败状态；过膨胀另给域评估（pe、pa/pe、匹配面积比），不输出外推值
- **循环三本账同时闭合**：开式和富氧补燃用同一绝热单轴求解器，涡轮出口压力由轴功反解，质量/轴功/焓/元素残差逐项输出
- **结果可复核**：13744项检查；与NASA CEA同源对照（甲烷燃烧室温度最大差0.0044 K）；本次演示页的2213个点可一键重算核对

**讲稿**：我们的工作可以概括成四点。第一，计算链从液体入口一直算到循环闭合，核心全部是C17，运行时不调用CEA。第二，模型越出适用域时程序直接拒算，并告诉你越在哪里，比如过膨胀时给出匹配面积比，而不是输出一个看起来合理的假数。第三，开式和补燃两种循环用同一个求解器，质量、轴功、能量三本账同时闭合。第四，所有结果都能复核，后面会给验证数据。

## P4 方法：一条计算链（约60秒）

- 使用[计算入口流程图](../docs/architecture/report-flow.svg)或 live panel 截图
- 三个要点：给定入口焓和元素库存求HP平衡；冻结喷管从声速喉部膨胀到给定面积比；循环模型闭合质量、轴功和焓三本账
- 一句话写公式：`c*=Pc·At/ṁ`，`F=CF·Pc·At`，`Isp=F/(ṁ·g0)`——P5要用

**讲稿**：给定入口焓和元素库存，求九种气相产物的定焓定压平衡，得到燃烧室状态；冻结喷管从声速喉部膨胀到给定面积比；循环模型再把泵、预燃室、涡轮、主室连起来闭合三本账。这里记住两个关系：固定室压和喉面积时，流量由c*决定，推力由推力系数CF决定。下一页的结果就靠这两个关系解释。

## P5 结果一：推进剂取舍——比冲收益体现在省流量（约90秒，含演示约40秒）

- **先给结论**：同室压、同喉面积下，甲烷比冲高13.85 s、流量低4.46%，推力只差−0.20%
- 机制：`F=CF·Pc·At`，推力由CF决定，与c*无关；c*高 → `ṁ=Pc·At/c*`低 → 同推力少用推进剂 → 比冲高
- 数据表：Pc=10 MPa、At=0.01 m²、面积比10、真空、O/F=2.6，甲烷324.43 s/172.64 kN/54.26 kg/s，RP-1 310.57 s/172.98 kN/56.80 kg/s
- **现场演示（页1）**：拖O/F滑块，右图推力差在O/F≈2.9穿过零线（2.8时−95 N，3.4时+278 N），比冲与流量差一直成镜像
- **条件**：两推进剂入口状态不同，同O/F不等于同当量比；这是方法成对比较，不是燃料排名；推进剂密度/贮箱体积未计算

**讲稿**：第一个结果是推进剂取舍。同一室压、同一喉面积下，甲烷比冲高约14秒。推力呢？只差0.2%。原因在公式里：推力等于CF乘Pc乘At，室压和喉面积相同时只看推力系数，c*根本不进入推力。c*的作用在流量上：甲烷c*更高，同样的喉部只通过少4.5%的推进剂，比冲收益就是这部分省下的流量。（切到演示页）拖动混合比可以看到，推力差在O/F 2.9附近变号，所以推力差不能当作选推进剂的依据；真正要权衡的是比冲换来的流量节省，和甲烷密度低带来的贮箱体积，后者我们没有计算。

## P6 结果二：喷管面积比——收益递减，代价加速（约70秒）

- **先给结论**：面积比10→20→40，比冲增益13.05→10.37 s；每平方米换来的比冲从38.5降到15.3 s/m²——腰斩
- 图：`docs/area-ratio-tradeoff.svg`（双面板：比冲收益/出口面积代价）
- **条件与边界**：给定热状态循环情景（100 kg/s、5 MPa/3300 K）；5 kPa背压下损失1.75→6.93 s；长度/质量/冷却未算

**讲稿**：第二个结果是喷管面积比。三个计算点显示增益递减：10到20增加13秒，20到40只增加10.4秒，但出口面积从0.34扩到1.36平方米。按单位面积算，后半段每平方米只换15秒，是前半段的四成。同时背压损失随面积比增大。所以大喷管只对真空任务剖面有明确意义，受级段直径约束的设计要在这个收益/代价比上做取舍。

## P7 结果二续：海平面过膨胀——同一枚喷管，两个世界（约80秒，含演示约40秒）

- **先给结论**：面积比40在海平面 pa/pe≈6.07 远过膨胀；该背压匹配面积比约9.92；真空收益与海平面匹配差23.4 s
- regime 评估表（理想pe、匹配面积比、0.4pa经验参考线）
- **现场演示（页2）**：背压切海平面、面积比拖到40——比冲卡片显示“C拒算”，同时给出pe=17.2 kPa、pa/pe=5.88、匹配面积比10.91；切回真空即恢复
- **条件**：报告7.4为定比热情景（6.07/9.92），演示页为液甲烷推力室（5.88/10.91），模型不同、量级一致；0.4pa是经验参考不是分离预测

**讲稿**：同一枚面积比40的喷管，在海平面远过膨胀，理想出口压力只有背压的六分之一。域评估给出的匹配面积比约10，和面积比40之间的真空比冲差23秒。这就是一级发动机面对的取舍：按海平面匹配设计，还是保留真空收益。（切到演示页）把背压切到海平面、面积比拉到40，程序不给比冲，直接拒算，同时告诉我们过膨胀多少、匹配面积比是多少。这页的数是液甲烷推力室，和报告的定比热情景模型不同，但量级一致。

## P8 结果三：开式与补燃循环如何闭合（约90秒，可用演示页3代替静态页）

- **先说清前提**：两情景燃料、混合比、泵压都不同——这是两个各自的闭合检查，不是对比实验
- 共同输入：总供给100 kg/s、主室10 MPa、主喷管面积比8、海平面背压
- 开式：CH4/O2，支路1.934 kg/s外排贡献2.636 kN（不能漏记）；整机290.539 kN、296.268 s
- 补燃：RP-1替代物，回流74.630 kg/s与新鲜燃料25.370 kg/s混合；涡轮出口17.947 MPa > 11 MPa下限；整机285.497 kN、291.126 s
- 检查：两处燃烧Q=0、元素库存、质量流量、轴功残差 < 1 W
- 两个二级开式情景输入相同，只画一个，不计为两个验证点

**讲稿**：第三个结果是循环闭合。先说明：两个情景的燃料和供给压力不同，所以我们不做循环优劣比较，看的是各自的账能不能闭上。开式循环有1.934公斤每秒的支路外排，它仍贡献2.636千牛推力，漏记就会低估性能。补燃循环把74.6公斤每秒回流燃气与新鲜燃料混合，轴功平衡求出的涡轮出口压力17.9兆帕，高于注入主室所需的11兆帕下限，功率账成立。两列的残差都在1瓦以内。

## P9 判断：小组的四条取舍意见（约70秒）

- 1. 同喉面积比较推进剂，比冲收益体现为省流量而非推力；比较前须说明固定的是喉面积还是推力（P5）
- 2. 面积比20以上收益/代价比腰斩（P6）
- 3. 海平面匹配与真空收益差23.4 s，一级喷管的量级取舍（P7）
- 4. 外排必须计入推力账，+1406.9 N（P8；注意这是给定热状态循环的轴向投影0→1算例，约占0.5%，与演示页开式情景的2.636 kN/0.91%是不同算例）
- 每条标注输入条件；换输入即需重算

**讲稿**：综合这些计算，小组提出四条判断。第一，同喉面积比较推进剂时，比冲收益体现为省流量，推力几乎不变，所以比较之前要先说清固定的是什么。第二，面积比20以上单位面积收益腰斩。第三，海平面匹配与真空收益之间是23秒量级的取舍。第四，外排流量必须计入推力账。每条判断都标注了输入条件，替换输入就要重新计算。

## P10 为什么可信：程序与验证（约60秒）

- C17纯计算核心、13744项验证检查项全部通过
- 与CEA同源对照：甲烷路径47次运行对18张参考卡，HP温度最大差0.0044 K；RP-1 33次运行对21张卡
- 拒算本身也被测试：过膨胀、O/F越域、方法域外输入各有预期失败用例
- live panel 或流程图作背景；完整验证矩阵在报告7.7节

**讲稿**：支撑这些结果的程序是C17纯计算核心，13744项检查全部通过，并与NASA CEA做了同源对照：甲烷路径47次运行对18张参考卡，燃烧室温度最大差0.0044开尔文。拒算行为本身也有测试：该失败的输入必须失败。这些对照检查的是软件在相同物性下算得对不对；我们没有发动机实验数据。

## 提问预案（Q&A）

| 可能问题 | 回答要点 |
|---|---|
| 为什么不做真实发动机性能？ | 当前已核验来源未组成同一构型与工况的完整输入卡；逐项缺口与影响见参数台账，计算保留声明假设 |
| c*高为什么推力不高？ | 固定Pc/At时F=CF·Pc·At，c*只决定流量；比冲=F/(ṁg0)，收益来自流量下降 |
| 甲烷O/F滑块为什么从2.4开始？ | 九气相模型无凝聚碳；O/F=0.5时C程序仍会返回结果但燃烧室残余CH4约49%，属富燃凝聚风险区，演示页主动限定在2.4–4.0 |
| 发生器O/F=1.0会不会析碳？ | 九气相模型不含凝聚碳，这是已声明边界（报告/输出limitations）；该工况残余CH4约14%，正是此假设影响最大的区域 |
| 演示页的数是前端算的吗？ | 不是。tools/demo_data.py调用已测Release exe共2213次，结果嵌入页面；`--check`重跑并逐字段比对 |
| 和CEA比差在哪？ | 同源物性、不同实现；连续液体和RP-1各按档案范围报告差值，不能统称≤0.02K或证明全域正确；CEA还支持更多产物、凝聚相和平衡喷管 |
| 0.004406 K是什么口径？ | 燃烧室HP温度的最大差；全字段最大差是喉部截面0.005602 K（fuel_hot工况），两者都在CEA打印精度以内 |
| 煤油怎么处理的？ | 固定RP-1锚点方法研究，限定域；富燃域九气相奇异/凝聚碳已登记为边界；国产煤油组成未知，不绑定型号 |
| 0.4pa分离判据可靠吗？ | Summerfield型经验提示，给"参考线"不是预测；真实分离受激波/边界层/喷管型面影响，超出模型范围 |
| 循环旧版为什么拒绝回流？ | 旧`prescribed_thermal_cycle_v1`只有给定热状态外排，仍拒绝回流；新`adiabatic_single_shaft_cycle_v1`另行闭合假设回流的元素、焓、轴功和压力，但不等于实机标定 |
| 为什么用C不用Python？ | 课程要求核心计算C语言；C核心无I/O依赖可移植，Python只用在测试与治理工具 |
| 验证是独立实验吗？ | 没有发动机实验数据。保存的CEA卡使用同源物性，检查的是这些输入下的软件结果 |
