- 副题：从文献调查到 C 语言热化学计算

**讲稿**：各位老师同学好，我们组的题目是朱雀三号和长征十号乙两型可重复使用运载火箭的动力系统研究。汇报分三块：查到了什么、算了什么、结论和边界在哪里。

## P2 研究对象：两型动力系统（约60秒）

- 表格：四个级段 ×（构型/推进剂/台数/已知动作）
  - 朱雀三号遥一一级：9台TQ-12A、液氧甲烷、整箭起飞推力7542 kN、起飞质量约560 t、一级回收
  - 朱雀三号遥一二级：1台TQ-15A真空型、二次起动
  - 长征十号乙首飞一级：液氧煤油、7台百吨级（5台可摇摆/二次起动、2台固定）、整箭推力原文约890/900吨级（吨力口径）、网系捕获回收
  - 长征十号乙首飞二级：液氧甲烷、140吨级推力量级描述，不是完整单机性能卡
- 配图建议：两型构型示意（引用来源标注）

**讲稿**：研究对象固定为朱雀三号遥一和长十乙首飞构型。遥一是全甲烷方案：一级9台天鹊12A、二级一台真空型天鹊15A。长十乙一级液氧煤油、7台百吨级发动机，二级液氧甲烷。多次起动、节流和回收需求来自各自来源，不能把产品后续版本的能力移给首飞构型；当前稳态方法计算也不验证起动瞬态或回收可靠性。构型出处见四级段研究与逐字段台账。

## P3 关键约束：公开数据决定研究定位（约45秒）

- 左：能查到的——构型、推进剂、台数、整箭级推力
- 右：现存已核验原文尚未凑齐的一致输入——单机室压、喉部面积、面积比、主室O/F、入口状态、循环细节
- 底部一行结论：当前证据不足以建立真实性能卡 → 计算是声明假设下的方法算例

**讲稿**：当前已保存并核验的原文还不足以为同一构型、级段和工况建立完整输入卡。这是现有证据的限制，不能扩大成公开资料中不存在这些参数。两型直接原文截止10月3日，后续产品与专题核验各按自己的日期。给定假设下的算例用于解释课程理论，不声称是真实型号性能。

## P4 程序是什么：一条计算流水线（约60秒）

- 候选图：`docs/architecture/live/slide-flow.svg`（排版时选静态帧；浏览器动效演示待现场环境确认）
- 标注：C17纯核心、Windows发布版、失败显式返回

**讲稿**：程序叫 rocketperf，C语言单进程，Windows控制台发布。流水线就是推力室的主线：物性用NASA九系数多项式，燃烧求定焓定压化学平衡，喷管从声速喉部推到出口，最后按 F=m·ve+(pe−pa)Ae 计账。三种入口：交互菜单逐项输入——对应"人工从屏幕输入"的要求；算例文件可复跑；命令行批量。演示后面有。

## P5 核心算法（约60秒）

- 左：HP平衡 = 元素库存守恒 + 九气相平衡闭合 → 绝热温度+组成
- 右：冻结喷管 = 组成沿程不变、比热随温变；声速喉部→阻塞流量→面积比求出口
- 底部：TP平衡用Newton迭代、解析Jacobian与主元消去；HP外层和喷管用二分夹逼，另查守恒残差与有效域

**讲稿**：物性库有10种气体，当前CHO平衡选其中9种，N2未参加这个平衡系统。TP组成求解用Newton迭代、解析Jacobian和主元消去；HP外层以温度夹逼焓残差。冻结喷管沿程保持组成，比热随温度变，以声速条件和面积比求喉部及出口；这部分也用夹逼求根。残差和有效域检查失败时显式返回，不输出假结果。

## P6 验证：我们凭什么信这些数（约50秒）

- 四层证据：解析极限 → 守恒残差与失败契约 → CEA同源对照 → 当前构建与交付质量
- 连续液体：47次C运行/18张参考卡，最大ΔT约0.004406 K、Δc*约0.003504 m/s；RP-1：33次运行/21张参考卡，原限定域和扩展点分别解释
- 诚实标注：对照是同源物性软件互验=方法级验证，不是独立实验

**讲稿**：验证分四层。先查解析极限，再查守恒、无效输入和失败输出保持。参考对照按各自档案解释：连续液体47次C运行对18张CEA参考卡，最大温差约0.0044K；RP-1原限定域按0.02K温差门限验收，但扩展点存在约0.31至0.46K温差，不能合并说全部小于0.02K。测试断言数量不等于独立物理工况数量。同源物性软件对照支持所测范围内的方法一致性，不是独立实验，也不证明所有工况或真实发动机。

## P7 算例一：液态甲烷基线与推进剂对比（约60秒）

- 基线卡：Pc=10 MPa、O/F=3.4、面积比10、真空 → T=3602.8 K、c*=1811.0 m/s、F=173.7 kN、Isp=320.8 s
- 对比条：另一个算例采用甲烷/RP-1各O/F=2.6，同Pc=10 MPa、At=0.01 m²、面积比10、真空：甲烷Isp +13.85 s、推力 −343.6 N
- 一句话：同喉面积下甲烷比冲高、推力低——性能评价要多量并看

**讲稿**：液态甲烷基线用10兆帕、O/F 3.4、喉面积0.01平方米、面积比10和真空，温度3602.8K、比冲320.8秒。成对比较是另一张输入卡：两种推进剂各用O/F 2.6，室压、喉面积、几何和背压相同，入口身份各自保留。同质量O/F不等于同当量比。这组条件下甲烷比冲高13.85秒、推力低343.6牛，说明比冲与推力需要一起评价。

## P8 算例二：海平面过膨胀研究情景（约75秒）

- 情境：定比热L0假设，P0=8 MPa、T0=3400 K、γ=1.2、R=350 J/(kg·K)、At=0.01 m²、面积比40、pa=101.325 kPa
- 诊断卡：pe≈16.7 kPa（<背压101.3 kPa）、pa/pe≈6.07、匹配面积比≈9.9、0.4pa经验参考面积比≈20.0、含压力项推力≈110.2 kN
- 边界声明：regime诊断=理想解+经验提示，不预测真实分离位置

**讲稿**：第二组采用明确的定比热假设，不代表两型一级发动机。面积比40、背压101.325kPa时，理想出口压力约16.7kPa，背压约为它的6.07倍。附着求解接口对此返回域外；域评估仍提供理想解、带压力项的推力及两个公式反解面积比。pa大于pe说明压力失配，不能单凭这个条件断言实际分离。匹配面积比约9.9和0.4pa经验参考约20是理想模型参考量，不是喷管改装建议或真实分离位置预测。

## P9 算例三：改进研究——收益与代价一起算（约60秒）

- 面积比10→20→40：真空比冲302.1→315.1→325.5 s，出口面积0.34→1.36 m²，5 kPa环境损失1.7→6.9 s
- 支路排气投影+1：推力+1406.9 N、比冲+1.43 s——发动机计账不能漏外排
- 入口焓升：比冲+0.28 s但推力−9.7 N——单看比冲会误判

**讲稿**：第三组把收益和代价一起算。给定热状态循环情景中，面积比10到40的真空比冲上升约23秒，出口面积放大四倍，5kPa背压损失也增加；这三点不能推出无限增大面积比或真实喷管选型结论。同一合成循环里计入支路轴向排气投影，推力增加约1407牛。另一个连续液体、固定室压和喉面积的入口焓响应情景中，比冲微升但推力略降。不同模型和流量约束分别解释，不能拼成真实发动机改装收益。

## P10 结论、边界与分工（约50秒）

- 结论三条：事实面查清（两型构型与复用需求）；方法面打通（NASA9→HP→冻结喷管全C实现+方法级验证）；分析面有数（多量并看的改进结论）
- 边界四条：无激波/分离/侧载；煤油仅固定替代物方法研究；无整机循环闭合；无独立实验验证
- 分工一行（见贡献记录）

**讲稿**：现有原文支持按构型和级段解释两型工作方案；C实现完成物性、平衡和冻结喷管链条，方法对照与算例提供有条件的定量结论。RP-1已实现固定替代物方法，仍不代表国产煤油批次；激波、分离、侧载、完整整机循环和独立实验均未覆盖。当前来源缺少一致真实输入卡，缺项保留为未知。组员贡献需要本人确认后进入最终稿。

## 提问预案（Q&A，5分钟）

| 可能问题 | 回答要点 |
|---|---|
| 为什么不做真实发动机性能？ | 当前已核验来源未组成同一构型与工况的完整输入卡；逐项缺口与影响见参数台账，计算保留声明假设 |
| 和CEA比差在哪？ | 同源物性、不同实现；连续液体和RP-1各按档案范围报告差值，不能统称≤0.02K或证明全域正确；CEA还支持更多产物、凝聚相和平衡喷管 |
| 煤油怎么处理的？ | 固定RP-1锚点方法研究，限定域；富燃域九气相奇异/凝聚碳已登记为边界；国产煤油组成未知，不绑定型号 |
| 0.4pa分离判据可靠吗？ | Summerfield型经验提示，给"参考线"不是预测；真实分离受激波/边界层/喷管型面影响，超出模型范围，报告全程标注 |
| 循环为什么"拒绝回流"？ | 外排原型是给定热状态合成计账；回流组成闭合需要泵后入口/喷注压降等输入和参考，缺据不硬扩 |
| 比冲高推力低矛盾吗？ | 不矛盾：mdot=Pc·At/c*，同喉面积下高c*推进剂流量低；推力=F(流量,速度,压力项)是另一本账 |
| 为什么用C不用Python？ | 课程要求核心计算C语言；C核心无I/O依赖可移植，Python只用在测试与治理工具 |
| 验证是独立实验吗？ | 不是。四层证据最高到同源软件对照；已如实标注证据等级，不冒称独立验证 |
