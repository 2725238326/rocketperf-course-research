## P1 封面（约20秒）

- 标题：重复使用运载火箭动力系统性能研究——朱雀三号与长征十号乙
- 副题：从文献调查到 C 语言热化学计算
- 组号/组员/日期

**讲稿**：各位老师同学好，我们组的题目是朱雀三号和长征十号乙两型可重复使用运载火箭的动力系统研究。汇报分三块：查到了什么、算了什么、结论和边界在哪里。

## P2 研究对象：两型动力系统（约60秒）

- 表格：四个级段 ×（构型/推进剂/台数/已知动作）
  - 朱雀三号一级：9台TQ-12A、液氧甲烷、整箭起飞推力7542 kN、约560 t、一级回收
  - 朱雀三号二级：1台TQ-15A真空型、二次起动
  - 长征十号乙一级：液氧煤油、7台百吨级（5台可摇摆/二次起动、2台固定）、约890–900 t级、网系捕获回收
  - 长征十号乙二级：液氧甲烷、140吨级描述
- 配图建议：两型构型示意（引用来源标注）

**讲稿**：先说事实面。朱雀三号是全甲烷方案：一级9台天鹊12A并联、二级一台真空型天鹊15A能二次起动，一级要回收。长十乙构型不一样：一级液氧煤油、7台百吨级发动机里5台能摇摆和二次起动、2台固定，回收方式走网系捕获；二级回到甲烷。复用对发动机意味着什么？并联冗余、多次起动、深度节流——这些是动力系统的工作包线，也是我们计算要覆盖的工况范围。

## P3 关键约束：公开数据决定研究定位（约45秒）

- 左：能查到的——构型、推进剂、台数、整箭级推力
- 右：查不到的——单机室压、喉部面积、面积比、主室O/F、入口状态、循环细节
- 底部一行结论：没有真实性能卡 → 所有计算是"声明假设下的方法算例"，不冒充真实型号

**讲稿**：但有一个必须说清楚的约束：两型发动机的单机关键参数——室压、喉部面积、喷管面积比、混合比、循环细节——公开资料都查不到一致可用的值。所以我们把研究定位成：事实归事实，计算归计算。所有数字都是给定假设下的方法算例，用来说明课程理论，不声称是这两型发动机的真实性能。这也是报告里数据声明那一页的意思。

## P4 程序是什么：一条计算流水线（约60秒）

- 图：输入（交互菜单/算例文件/CLI）→ NASA9物性 → HP化学平衡 → 冻结/L0喷管 → 推力比冲计账 → JSON/文本/归档
- 标注：C17纯核心、Windows发布版、失败显式返回

**讲稿**：程序叫 rocketperf，C语言单进程，Windows控制台发布。流水线就是推力室的主线：物性用NASA九系数多项式，燃烧求定焓定压化学平衡，喷管从声速喉部推到出口，最后按 F=m·ve+(pe−pa)Ae 计账。三种入口：交互菜单逐项输入——对应"人工从屏幕输入"的要求；算例文件可复跑；命令行批量。演示后面有。

## P5 核心算法（约60秒）

- 左：HP平衡 = 元素库存守恒 + 九气相平衡闭合 → 绝热温度+组成
- 右：冻结喷管 = 组成沿程不变、比热随温变；声速喉部→阻塞流量→面积比求出口
- 底部：数值策略——二分夹逼求根、守恒残差自检、越域显式拒绝

**讲稿**：算法两个核心。燃烧侧解九气相的化学平衡：固定焓和压力，元素库存守恒加上平衡常数，迭代出绝热燃烧温度和产物摩尔分数。喷管侧假设燃烧室冻结——组成不再变、比热随温度变，喉部按声速条件定流量，再由面积比求出口状态。数值上全是二分求根加守恒残差自检；不满足模型假设的工况直接返回域外状态，不输出假结果。

## P6 验证：我们凭什么信这些数（约50秒）

- 四层证据：解析极限（对教科书公式）→ 守恒自检（13k+项残差）→ CEA同源对照（33次运行/21张参考卡，ΔT≤0.02 K）→ 工程质量（双配置测试+44组CLI回归）
- 诚实标注：对照是同源物性软件互验=方法级验证，不是独立实验

**讲稿**：验证分四层。最底层对教科书解析公式，中间一万三千多项守恒残差自检，再往上和CEA同条件对照——33次运行对21张参考卡，燃烧温度差小于0.02K、特征速度差小于0.03米每秒。要诚实说明的是：CEA和我们用的是同源物性方法，这叫方法级验证，证明算法实现正确；不等于用实验数据验证了真实发动机。

## P7 算例一：液态甲烷基线与推进剂对比（约60秒）

- 基线卡：Pc=10 MPa、O/F=3.4、面积比10、真空 → T=3602.8 K、c*=1811.0 m/s、F=173.7 kN、Isp=320.8 s
- 对比条：同边界甲烷 vs RP-1：Isp +13.85 s、推力 −343.6 N
- 一句话：同喉面积下甲烷比冲高、推力低——性能评价要多量并看

**讲稿**：第一组算例。液态甲烷基线：10兆帕室压、O/F 3.4、面积比10真空，算出燃烧温度3602.8K、比冲320.8秒。再把甲烷和RP-1放在完全相同的边界下：甲烷比冲高13.85秒，但推力低343.6牛——固定喉面积下甲烷的流量通量低。所以"哪种推进剂好"没有单指标答案：比冲和推力是两张账。

## P8 算例二：海平面过膨胀——一级发动机的真实处境（约75秒）

- 情境：面积比40的喷管在海平面点火（一级发动机的实际处境）
- 诊断卡：pe≈16.7 kPa（<背压101.3 kPa）、pa/pe≈6.07、匹配面积比≈9.9、0.4pa经验参考面积比≈20.0、含压力项推力≈110.2 kN
- 边界声明：regime诊断=理想解+经验提示，不预测真实分离位置

**讲稿**：第二组是我们认为最有意思的算例。一级发动机点火的瞬间就在海平面：如果一个面积比40的喷管按10.13万帕背压工作，理想出口压力只有1.67万帕——深度过膨胀，附着流假设已经不成立。一般软件到这就报错了；我们加了一条域评估路径：不假装能算分离，但给出理想解的pe、过膨胀倍数6.07、这个背压下压力匹配所需的面积比约9.9、以及Summerfield型0.4pa经验参考对应的面积比约20。它回答"这个喷管为过膨胀设计了多少、往哪个方向改"，而不是"分离会在哪发生"——激波和分离位置需要更高阶模型，我们如实标注不算。

## P9 算例三：改进研究——收益与代价一起算（约60秒）

- 面积比10→20→40：真空比冲302.1→315.1→325.5 s，出口面积0.34→1.36 m²，5 kPa环境损失1.7→6.9 s
- 支路排气投影+1：推力+1406.9 N、比冲+1.43 s——发动机计账不能漏外排
- 入口焓升：比冲+0.28 s但推力−9.7 N——单看比冲会误判

**讲稿**：第三组是改进研究，要点是收益和代价必须一起算。面积比从10加到40，真空比冲多23秒，但出口面积放大四倍，而且一旦背压上来，环境损失反而更大——大面积比属于真空段，不属于海平面。第二个点：把支路涡轮排气的轴向推力算进去，推力多1400多牛——整机比冲的账不能漏外排流量。第三个点：入口焓升高，比冲微涨但推力反而降，因为室压和喉面积定了，c*变大流量就小。三个例子说明：评价改进必须多参数一起看。

## P10 结论、边界与分工（约50秒）

- 结论三条：事实面查清（两型构型与复用需求）；方法面打通（NASA9→HP→冻结喷管全C实现+方法级验证）；分析面有数（多量并看的改进结论）
- 边界四条：无激波/分离/侧载；煤油仅固定替代物方法研究；无整机循环闭合；无独立实验验证
- 分工一行（见贡献记录）

**讲稿**：收尾。结论三条：两型动力系统的构型和复用工作模式查清楚了；从物性到喷管的计算链全部C实现、通过了方法级验证；改进分析给出了有边界条件的定量结论。边界也如实摆出来：不算激波分离侧载、煤油只是替代物方法占位、没有整机循环闭合、没有独立实验对照。真实单机性能卡在公开资料里不存在，我们保留为未知而不是编数。分工见报告附录。谢谢，请老师同学提问。

## 演示预案（可替换P7–P8，约90秒）

若评委要求现场演示，用发布版 exe：

1. 裸跑 `rocketperf` → 菜单 → 选液态燃烧+喷管 → 逐项输入（默认值回车）→ 人读结果表。
2. `rocketperf nozzle regime cases\research\s3_sealevel_regime.ini --text` → 过膨胀域评估表。
3. `rocketperf cases` → 展示可复跑算例列表。

讲解词：菜单对应"参数人工输入"，算例文件对应可复现归档；JSON是机器契约，`--text`是人读输出；过膨胀不静默、给诊断不冒充分离预测。

## 提问预案（Q&A，5分钟）

| 可能问题 | 回答要点 |
|---|---|
| 为什么不做真实发动机性能？ | 单机性能卡所需参数（Pc/At/面积比/O-F/入口/循环）公开资料无一一致可用；编造比"方法算例+边界声明"更不可取——这是研究诚信问题 |
| 和CEA比差在哪？ | 同源方法、实现独立；对照差≤0.02K证明实现正确；CEA有平衡喷管/更多产物/凝聚相，我们只有冻结喷管九气相 |
| 煤油怎么处理的？ | 固定RP-1锚点方法研究，限定域；富燃域九气相奇异/凝聚碳已登记为边界；国产煤油组成未知，不绑定型号 |
| 0.4pa分离判据可靠吗？ | Summerfield型经验提示，给"参考线"不是预测；真实分离受激波/边界层/喷管型面影响，超出模型范围，报告全程标注 |
| 循环为什么"拒绝回流"？ | 外排原型是给定热状态合成计账；回流组成闭合需要泵后入口/喷注压降等输入和参考，缺据不硬扩 |
| 比冲高推力低矛盾吗？ | 不矛盾：mdot=Pc·At/c*，同喉面积下高c*推进剂流量低；推力=F(流量,速度,压力项)是另一本账 |
| 为什么用C不用Python？ | 课程要求核心计算C语言；C核心无I/O依赖可移植，Python只用在测试与治理工具 |
| 验证是独立实验吗？ | 不是。四层证据最高到同源软件对照；已如实标注证据等级，不冒称独立验证 |
